### Technical Metadata Brief: Homotopy Category of a Simplicial Set (Lean 4)

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `OneTruncation₂ S` | `SSet.Truncated 2 → Type u` | Underlying reflexive quiver (0-simplices as objects, 1-simplices as morphisms with source/target constraints) of a 2-truncated simplicial set `S`. |
| `OneTruncation₂.Hom` | `structure` | Hom-types: triples `(edge, src_eq, tgt_eq)` encoding a 1-simplex and equalities to endpoints. |
| `oneTruncation₂` | `SSet.Truncated 2 ⥤ ReflQuiv` | Functor extracting the reflexive quiver from a 2-truncated simplicial set. |
| `δ₂ i`, `σ₂ i` | `SimplexCategory.Truncated 2` morphisms | Abbreviations for face/degeneracy maps in the 2-truncated simplex category. |
| `ι0₂`, `ι1₂`, `ι2₂` | `[0]₂ → [2]₂` | Morphisms picking out initial/middle/final vertices of a 2-simplex. |
| `ev0₂`, `ev1₂`, `ev2₂` | `V _[2]₂ → OneTruncation₂ V` | Vertex evaluation maps on 2-simplices. |
| `δ0₂`, `δ1₂`, `δ2₂` | `[1]₂ → [2]₂` | Face maps for 2-simplices (0th, 1st, 2nd). |
| `ev01₂`, `ev12₂`, `ev02₂` | `V _[2]₂ → Hom(...)` | Arrows in `OneTruncation₂ V` induced by faces of a 2-simplex. |
| `HoRel₂` | `inductive Prop` | Hom-relation generated by 2-simplices: `f₀₂ = f₀₁ ≫ f₁₂` when `f₀₁, f₁₂, f₀₂` are 2nd, 0th, 1st faces of a 2-simplex. |
| `Truncated.HomotopyCategory V` | `Type u` | Quotient of free category on `OneTruncation₂ V` by `HoRel₂`. |
| `quotientFunctor V` | `Cat.FreeRefl (OneTruncation₂ V) ⥤ V.HomotopyCategory` | Canonical projection functor. |
| `mapHomotopyCategory F` | `V.HomotopyCategory ⥤ W.HomotopyCategory` | Functor induced by map `F : V ⟶ W` of 2-truncated simplicial sets. |
| `hoFunctor₂` | `SSet.Truncated 2 ⥤ Cat` | Functor sending `V ↦ V.HomotopyCategory`, `F ↦ mapHomotopyCategory F`. |
| `hoFunctor` | `SSet ⥤ Cat` | Full homotopy category functor: `truncation 2 ⋙ hoFunctor₂`. |
| `OneTruncation₂.ofNerve₂` | `nerveFunctor₂ ⋙ oneTruncation₂ ≅ ReflQuiv.forget` | Natural isomorphism showing quiver of nerve ≅ underlying quiver of category. |
| `OneTruncation₂.nerveHomEquiv` | `(X ⟶ Y) ≃ (nerveEquiv X ⟶ nerveEquiv Y)` | Hom-equivalence over `nerveEquiv`, key for nerve comparison. |

**Theorems:**
- `δ₂_zero_comp_σ₂_zero`, `δ₂_one_comp_σ₂_zero`: Identities for compositions of faces and degeneracies.
- `HoRel₂.mk'`: Generalized constructor for `HoRel₂` using arbitrary arrows with specified edges.
- `HomotopyCategory.lift_unique'`: `quotientFunctor` is an epimorphism in `Cat`.
- `hoFunctor₂.map_id`, `hoFunctor₂.map_comp`: Verifies `hoFunctor₂` is a functor.
- `hoFunctor₂_naturality`: Naturality square for `mapHomotopyCategory`.

#### **2. Naming Conventions**

- **Prefixes:**
  - `δ₂`, `σ₂`: Face/degeneracy maps in `SimplexCategory.Truncated 2`.
  - `ιi₂`: Vertex inclusions `[0]₂ → [2]₂`.
  - `evi₂`: Evaluation of `i`-th vertex of a 2-simplex.
  - `HoRel₂`: Homotopy relation (2-truncated).
  - `oneTruncation₂`: Underlying quiver of 2-truncated sSet.
  - `nerveEquiv`, `nerveHomEquiv`: Equivalences for nerve comparison.

- **Suffixes:**
  - `_₂`: Indicates 2-truncated context (e.g., `δ₂`, `ι0₂`, `ev0₂`, `HoRel₂`).
  - `₂`: In `OneTruncation₂`, `hoFunctor₂`, `Truncated.HomotopyCategory`.

- **Structure fields:**
  - `.edge`, `.src_eq`, `.tgt_eq`: Components of a morphism in `OneTruncation₂.Hom`.

#### **3. Tactic Stack**

Frequently used tactics in proofs:
- `simp only [...]`: Simplification with custom lemmas and `reassoc` attributes.
- `rw [...]`: Rewriting using naturality, composition, and equality lemmas.
- `ext`: Extensionality for structures (e.g., `OneTruncation₂.Hom.ext`).
- `dsimp`: Simplify definitional equalities.
- `apply CategoryTheory.Quotient.sound`: To prove relations in quotient categories.
- `obtain rfl := ...`: Unpack equalities via `congr_arg` and `ComposableArrows.ext₀/₁`.
- `all_goals`: Applied uniformly across goals (e.g., in `mapHomotopyCategory`).
- `rfl`, ` rfl`: Reflexivity and definitional equality handling.
- `Functor.assoc`, `Functor.id_comp`, `comp_id`, `id_comp`: Category-theoretic rewrites.

#### **4. Proof Logic**

- **Structure-level reasoning:** Proofs often proceed by:
  1. Extending morphisms (`ext`) to reduce to edge/component equalities.
  2. Rewriting using naturality and simp lemmas (`map_map_of_eq`, `δ_comp_σ`, etc.).
  3. Unfolding definitions (`simp only [...]`) to reduce to concrete simplex maps.
  4. Using `quotientFunctor` universal property (`Quotient.lift_unique'`) to prove functoriality or uniqueness.

- **Inductive definitions:** `HoRel₂` is inductively generated by 2-simplices; proofs about it use `induction` or `apply HoRel₂.mk'`.

- **Naturality & coherence:** For `ofNerve₂.natIso`, proofs use `ReflPrefunctor.ext` and simplify with `simp` over many definitions (nerve, truncation, quiver actions).

- **Quotient-based constructions:** Homotopy category defined via `Quotient`, so functors out of it use `Quotient.lift`/`Quotient.map`, verified via `lift_unique'`.

#### **5. Imports & Scope**

**Primary imports:**
- `Mathlib.AlgebraicTopology.SimplicialSet.Coskeletal`: For truncation and coskeletal constructions.
- `Mathlib.CategoryTheory.Category.ReflQuiv`: Reflexive quivers and free categories.
- `Mathlib.Combinatorics.Quiver.ReflQuiver`: Reflexive quiver machinery.

**Scope:**
- Universe polymorphic: `universe v u`
- Works with `SSet.{u}` (simplicial sets) and `SSet.Truncated.{u} 2` (2-truncated sSets).
- Targets `Cat.{u, u}` (locally small categories).
- Central to future work: `hoFunctor` is intended to be left adjoint to the nerve, via factorization through 2-truncated sSets (uses 2-coskeletality of nerves).
