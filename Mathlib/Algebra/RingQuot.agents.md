### Technical Metadata Brief: `Mathlib.RingTheory.Quotient.NonComm`

---

#### **1. Key Definitions & Theorems**

| Name | Type / Purpose |
|------|----------------|
| `Rel r` | Inductive relation on `R`, generated from a base relation `r : R → R → Prop` by closure under addition, multiplication (left/right), and (in rings) negation/subtraction. Represents the *ideal generated by* `r`. |
| `ringCon r` | `RingCon R`: the ring congruence `Relation.EqvGen (Rel r)`. Encodes the smallest ring congruence containing `r`. |
| `RingQuot r` | Quotient type `Quot (Rel r)`, equipped with ring/semiring/algebra structure. Represents the quotient of `R` by the ideal generated by `r`. |
| `mkRingHom r : R →+* RingQuot r` | Canonical quotient map (ring homomorphism). Sends `x ↦ ⟨Quot.mk _ x⟩`. |
| `mkAlgHom S s : A →ₐ[S] RingQuot s` | Canonical quotient map for `S`-algebras. |
| `lift {r} : { f : R →+* T // ∀ ⦃x y⦄, r x y → f x = f y } ≃ (RingQuot r →+* T)` | Universal property: ring homs factoring through `RingQuot r` correspond to ring homs respecting `r`. |
| `liftAlgHom S {s} : { f : A →ₐ[S] B // ∀ ⦃x y⦄, s x y → f x = f y } ≃ (RingQuot s →ₐ[S] B)` | Universal property for algebras. |
| `ringQuotToIdealQuotient r`, `idealQuotientToRingQuot r`, `ringQuotEquivIdealQuotient r` | In the *commutative* case, `RingQuot r ≃+* B ⧸ Ideal.ofRel r`. Shows agreement with classical ideal quotient. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `Rel` — inductive relation generation (e.g., `Rel.of`, `Rel.add_left`, `Rel.mul_right`)
  - `ringCon` — ring congruence construction
  - `mkRingHom`, `mkAlgHom` — canonical quotient maps
  - `lift`, `liftAlgHom` — universal factorization maps
  - `preLift`, `preLiftAlgHom` — internal helper for `lift`
  - `ringQuot*`, `idealQuotient*` — equivalence between constructions in commutative case

- **Suffixes**:
  - `_quot` — quotient element constructors (e.g., `add_quot`, `mul_quot`, `zero_quot`)
  - `_def` — definitional equalities for operations (e.g., `add_def`, `zero_def`)
  - `_rel` — properties of the quotient map w.r.t. the generating relation (e.g., `mkRingHom_rel`, `mkAlgHom_rel`)
  - `_surjective`, `_ext`, `_unique` — standard categorical/uniqueness lemmas

- **Notable patterns**:
  - `Quot.map`, `Quot.lift`, `Quot.map₂` used heavily to define operations on quotients.
  - `⟨Quot.mk _ x⟩` used to embed elements of `R` into `RingQuot r`.
  - `Quot.inductionOn`, `Quot.sound`, `Quot.mk.injEq` used in proofs.

---

#### **3. Tactic Stack**

- **Core automation**:
  - `simp` / `simp only` — dominant tactic; simplifies using definitional equalities, `mkRingHom_def`, `add_quot`, etc.
  - `rw` — rewriting using definitions and lemmas like `add_quot`, `mul_quot`, `mkRingHom_rel`.
  - `induction` — structural induction on `Rel r`, `Relation.EqvGen`, or natural numbers (`nsmul`, `npow`).
  - `rintro` / `intro` — for destructuring existentials and hypotheses.
  - `congr_arg`, `congr_arg₂` — to lift equalities through function applications.

- **Ring-specific**:
  - `ring` / `ring1` — not used here (likely avoided due to noncommutativity or irreducibility concerns).
  - `dsimp`, `simp_rw` — for delicate definitional simplifications (e.g., in `npow` proof).
  - `exact`, `refine`, `apply` — for constructing proofs of `Rel` closure properties.

- **Equivalence & congruence**:
  - `Relation.EqvGen.*` tactics (e.g., `rel`, `refl`, `symm`, `trans`) used in `ringCon` proofs.

- **Quotient-specific**:
  - `Quot.sound`, `Quot.inductionOn`, `Quot.map₂_mk`, `mk.injEq` — for reasoning about equality in quotients.

---

#### **4. Proof Logic**

- **Inductive structure**:
  - Proofs about `Rel r` proceed by **induction on the inductive generation** of `Rel r` (cases: `of`, `add_left`, `mul_left`, `mul_right`, and derived `add_right`, `neg`, `sub_left/right`).
  - Proofs about `ringCon r` use **induction on `Relation.EqvGen`**, leveraging its universal property as the smallest equivalence containing `Rel r`.

- **Universal properties**:
  - `lift`/`liftAlgHom` proofs use:
    - `preLift` defined via `Quot.lift` (requires showing `f` respects `Rel r`).
    - `Quot.sound`/`Quot.inductionOn` to verify well-definedness.
    - `ext` + `mkRingHom_surjective` to prove uniqueness.

- **Commutative case alignment**:
  - `ringQuotEquivIdealQuotient` uses:
    - `Ideal.Quotient.lift` / `Ideal.Quotient.mk` to build maps in both directions.
    - `Submodule.span_induction` to verify that `mkRingHom` respects the ideal generated by `r`.
    - `ext` + `rfl` to show inverses.

- **Algebra structure**:
  - Verified via `Quot.map` with `Rel.smul`, and `Algebra.commutes'`, `smul_def'` proven via `Quot.ind'`.

#### **5. Imports & Scope**

- **Core dependencies**:
  ```lean
  import Mathlib.Algebra.Algebra.Hom
  import Mathlib.RingTheory.Congruence.Basic
  import Mathlib.RingTheory.Ideal.Quotient.Defs
  import Mathlib.RingTheory.Ideal.Span
  ```

- **Scope**:
  - Handles **noncommutative semirings/rings** via *relation-based* quotients (not ideal-based).
  - Extends to **`S`-algebras** (with `Algebra S R`) uniformly.
  - Proves agreement with classical ideal quotients **only in the commutative case** (`CommRing` section).
  - Avoids assuming `Ideal` (which is commutative-only in Mathlib), instead building congruences directly.

- **Design philosophy**:
  - `RingQuot` is defined via `Quot (Rel r)`, with operations defined via `Quot.map`/`Quot.lift`.
  - Definitions marked `irreducible_def` to prevent reliance on internal representation (except where diamonds arise, e.g., `natCast`, `intCast`).
  - Emphasizes *universal properties* over concrete representation.

--- 

This module provides a robust, general foundation for noncommutative quotients in Lean, avoiding reliance on `Ideal`, and enabling uniform treatment of rings, semirings, and algebras.
