**Technical Brief: `Basic.lean` — Linear Equivalences and Related Structures**

---

### 1. KEY DEFINITIONS & THEOREMS

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `restrictScalars` | `(f : M ≃ₗ[S] M₂) → M ≃ₗ[R] M₂` | Converts an `S`-linear equivalence to an `R`-linear equivalence when the `R`-action factors through `S`. |
| `Module.End.isUnit_iff` | `IsUnit f ↔ Function.Bijective f` | Characterizes invertible endomorphisms as bijective ones. |
| `automorphismGroup` | `Group (M ≃ₗ[R] M)` | Equips automorphism group with group structure via composition. |
| `automorphismGroup.toLinearMapMonoidHom` | `(M ≃ₗ[R] M) →* M →ₗ[R] M` | Monoid homomorphism embedding automorphisms into endomorphisms. |
| `applyDistribMulAction` | `DistribMulAction (M ≃ₗ[R] M) M` | Tautological action of automorphisms on the module. |
| `ofSubsingleton` | `M ≃ₗ[R] M₂` (when both are subsingletons) | Any two zero modules are linearly isomorphic. |
| `compHom.toLinearEquiv` | `R ≃ₗ[R] S` for `g : R ≃+* S` | Ring isomorphisms induce linear equivalences via scalar restriction. |
| `toLinearEquiv` (for `AddEquiv`) | `(e : M ≃+ M₂) → (∀ c x, e (c • x) = c • e x) → M ≃ₗ[R] M₂` | Lifts additive equivalences preserving scalar multiplication to linear equivalences. |
| `toNatLinearEquiv`, `toIntLinearEquiv` | `M ≃ₗ[ℕ] M₂`, `M ≃ₗ[ℤ] M₂` | Connect additive equivalences with `ℕ`/`ℤ`-linear equivalences. |
| `ringLmapEquivSelf` | `(R →ₗ[R] M) ≃ₗ[S] M` | Represents the forgetful functor via `R` (Yoneda for modules). |
| `addMonoidHomLequivNat`, `addMonoidHomLequivInt` | `(A →+ B) ≃ₗ[R] A →ₗ[ℕ] B`, `A →ₗ[ℤ] B` | Relate additive maps to linear maps over `ℕ`/`ℤ`. |
| `addMonoidEndRingEquivInt` | `AddMonoid.End A ≃+* Module.End ℤ A` | Ring isomorphism between additive endomorphisms and `ℤ`-linear endomorphisms. |
| `neg` | `M ≃ₗ[R] M` | Negation map as a linear equivalence. |
| `arrowCongr`, `arrowCongrAddEquiv` | `(M₁ →ₛₗ[σ₁₁'] M₁') ≃ₛₗ[σ₁'₂'] (M₂ →ₛₗ[σ₂₂'] M₂')` | Induced linear equivalence on hom-spaces from domain/codomain equivalences. |
| `conj`, `conjRingEquiv` | `Module.End R₁ M₁ ≃ₛₗ[σ₁₂] Module.End R₂ M₂` | Conjugation isomorphism on endomorphism rings/spaces. |
| `smulOfUnit`, `smulOfNeZero` | `M ≃ₗ[R] M` | Multiplication by a unit (or nonzero field element) is a linear equivalence. |
| `funCongrLeft` | `(n → M) ≃ₗ[R] m → M` for `e : m ≃ n` | Pullback along equivalence of function spaces. |
| `sumPiEquivProdPi`, `piUnique` | Product decompositions as linear equivalences | Categorical product decomposition for dependent products. |
