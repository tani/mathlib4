### Technical Metadata Brief: Free Constructions in Lean 4 (Mathlib)

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `FreeMagma α` | `Type u → Type u` (inductive) | Free magma over alphabet `α`: inductively generated by `of : α → FreeMagma α` and `mul : FreeMagma α → FreeMagma α → FreeMagma α`. |
| `FreeAddMagma α` | `Type u → Type u` (inductive) | Additive version of `FreeMagma`. |
| `FreeSemigroup α` | `Type u → Type u` (structure) | Nonempty lists: `head : α`, `tail : List α`. Represents free *semigroup* (associative multiplication). |
| `FreeAddSemigroup α` | `Type u → Type u` (structure) | Additive version of `FreeSemigroup`. |
| `Magma.AssocQuotient α` | `Type u → Type u` (quotient) | Quotient of magma `α` by associativity equivalence relation `AssocRel`. |
| `AddMagma.AssocRel α` / `Magma.AssocRel α` | `α → α → Prop` (inductive) | Generates associativity relations: `(x * y) * z ↔ x * (y * z)` and left-multiplication compatibility. |
| `FreeMagma.lift` | `(α → β) ≃ (FreeMagma α →ₙ* β)` | Universal property: magma homs from `FreeMagma α` correspond to functions `α → β`. |
| `FreeSemigroup.lift` | `(α → β) ≃ (FreeSemigroup α →ₙ* β)` | Universal property for free semigroups. |
| `Magma.AssocQuotient.lift` | `(α →ₙ* β) ≃ (AssocQuotient α →ₙ* β)` for semigroup `β` | Universal property of semigroup completion. |
| `FreeMagmaAssocQuotientEquiv α` | `Magma.AssocQuotient (FreeMagma α) ≃* FreeSemigroup α` | Isomorphism between associativity-quotient of free magma and free semigroup. |
| `FreeMagma.toFreeSemigroup` | `FreeMagma α →ₙ* FreeSemigroup α` | Canonical map factoring through associativity. |
| `FreeMagma.length` / `FreeSemigroup.length` | `FreeMagma α → ℕ`, `FreeSemigroup α → ℕ` | Counts number of `of` constructors (i.e., leaf elements). |
| `FreeMagma.traverse` / `FreeSemigroup.traverse` | `Traversable` instance | Enables mapping over structure while collecting effects. |
| `FreeMagma.instLawfulMonad` / `FreeSemigroup.instLawfulMonad` | `LawfulMonad` instance | Monadic structure with lawful behavior (e.g., associativity of `>>=`). |

#### **2. Naming Conventions**

- **Prefixes & Suffixes**:
  - `Free*`: Free algebraic constructions (`FreeMagma`, `FreeSemigroup`, `FreeAddMagma`, `FreeAddSemigroup`).
  - `AssocQuotient` / `AssocRel`: Quotienting by associativity.
  - `lift`: Universal property maps (e.g., `FreeMagma.lift`, `AssocQuotient.lift`).
  - `map`: Induced homomorphism from a function on generators.
  - `of`: Canonical embedding of generators (`α → FreeMagma α`, `α → FreeSemigroup α`).
  - `toFree*`: Canonical morphism *to* a more structured free object (e.g., `toFreeSemigroup`).
  - `length`, `repr`: Structural invariants (natural number, string representation).
  - `recOn*`, `induction_on`: Recursors/induction principles (e.g., `recOnMul`, `recOnPure`).
  - `hom_ext`: Extensionality lemmas for homomorphisms.

- **Additive Prefix**: `FreeAdd*`, `AddMagma.*`, `+` instead of `*`.

Frequently used tactics in proofs:

| Tactic | Usage |
|--------|-------|

| `ext` / `DFunLike.ext` | Extensionality for functions/homomorphisms. |

| `convert` / `congr` | Congruence closure for equality proofs. |
| `funext` | Extensionality for function equality. |
| `simp only [functor_norm, ...]` | Normalization for functor/traversable laws. |

#### **4. Proof Logic & Strategy**

- **Inductive Proofs**: Most properties (e.g., `length_pos`, `traverse_mul`, `lawful_traversable`) are proven by structural induction on `FreeMagma` or `FreeSemigroup` elements using `recOnMul` or `recOnPure`.
- **Quotient Induction**: For `AssocQuotient`, proofs use `AssocQuotient.induction_on` to reduce to representatives.
- **Universal Properties**: Proofs of isomorphisms (`lift`, `FreeMagmaAssocQuotientEquiv`) rely on:
  - Defining forward/backward maps via `lift`.
  - Showing they are inverses using extensionality (`hom_ext`) and simplification.
- **Monadic/Traversable Laws**: Verified via induction + simplification using:
  - `map_mul'`, `mul_bind`, `traverse_mul`.
  - Functor/traversable composition/naturality axioms.
- **Decidability & Equality**: `DecidableEq` instances derived via `decidable_of_iff'` and `FreeMagma.ext` / `FreeSemigroup.ext_iff`.

**Domain Scope**:  
This module formalizes **free algebraic structures** (magmas, semigroups) and their universal properties, with emphasis on:
- Constructive representation (inductive types, structures).
- Functoriality, monadic structure, and traversability.
- Associativity completion via quotienting.

It serves as foundational infrastructure for higher algebra (e.g., free groups, rings) and functional programming semantics in Lean.
