### Technical Brief: Bundled Subsemirings in Lean 4 (Mathlib)

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `Subsemiring R` | `Type u → Type u` | Bundled subsemirings of a non-associative semiring `R`. |
| `toSubmonoid`, `toAddSubmonoid` | `Subsemiring R → Submonoid R`, `→ AddSubmonoid R` | Projection to underlying multiplicative/additive structures. |
| `mem_bot` | `x ∈ (⊥ : Subsemiring R) ↔ ∃ n : ℕ, ↑n = x` | Characterizes bottom subsemiring (image of `ℕ → R`). |
| `mem_comap` | `x ∈ s.comap f ↔ f x ∈ s` | Membership in preimage subsemiring under ring hom `f`. |
| `mem_map` | `y ∈ s.map f ↔ ∃ x ∈ s, f x = y` | Membership in image subsemiring. |
| `map_le_iff_le_comap` | `s.map f ≤ t ↔ s ≤ t.comap f` | Adjunction between `map` and `comap`. |
| `gc_map_comap` | `GaloisConnection (map f) (comap f)` | `map ⊣ comap` Galois connection. |
| `equivMapOfInjective` | `s ≃+* s.map f` (for injective `f`) | Isomorphism between subsemiring and its injective image. |
| `rangeS` | `f.rangeS : Subsemiring S` | Subsemiring image (range) of ring hom `f`. |
| `mem_rangeS` | `y ∈ f.rangeS ↔ ∃ x, f x = y` | Membership in range subsemiring. |
| `center` | `Subsemiring R` | Center of a semiring: elements commuting with all others. |
| `centralizer s` | `Subsemiring R` | Centralizer of a subset `s ⊆ R`. |
| `closure s` | `Set R → Subsemiring R` | Subsemiring generated by a set `s`. |
| `mem_closure_iff` | `x ∈ closure s ↔ x ∈ AddSubmonoid.closure (Submonoid.closure s)` | Structural description of closure elements. |
| `closure_induction` | Induction principle for `closure` | General induction over generated subsemiring. |
| `mem_closure_iff_exists_list` | `x ∈ closure s ↔ ∃ L : List (List R), ...` | Concrete description: finite sums of finite products from `s`. |
| `gi` | `GaloisInsertion closure (↑)` | Closure forms GI with coercion to set. |
| `prod` | `Subsemiring R → Subsemiring S → Subsemiring (R × S)` | Product subsemiring. |
| `prodEquiv` | `s.prod t ≃+* s × t` | Isomorphism between product subsemiring and product of subsemirings. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `mem_`: Membership characterizations (`mem_bot`, `mem_comap`, `mem_map`, `mem_rangeS`, `mem_center_iff`, `mem_centralizer_iff`, `mem_closure`, etc.)
  - `coe_`: Coercion to set (`coe_bot`, `coe_sInf`, `coe_prod`, `coe_centralizer`, `coe_iSup_of_directed`, etc.)
  - `map_`, `comap_`: Image/preimage under ring hom (`map`, `comap`, `map_id`, `map_map`, `map_le_iff_le_comap`, `comap_comap`, etc.)
  - `eq_`, `le_`: Equality/inequality lemmas (`eq_top_iff'`, `le_centralizer_centralizer`, `closure_le`, `closure_mono`, etc.)
  - `induction`: Induction principles (`closure_induction`, `closure_induction₂`)

- **Suffixes**:
  - `_mem`: Membership criteria (`mem_*`)
  - `__iff`: Logical equivalences (`mem_*_iff`, `eq_*_iff`, `centralizer_eq_top_iff_subset`)
  - `_to*`: Projection to underlying structure (`toSubmonoid`, `toAddSubmonoid`)
  - `_Equiv`, `_equiv`: Isomorphisms (`prodEquiv`, `equivMapOfInjective`, `topEquiv`)
  - `_S`: Subsemiring-specific variants (`rangeS`, `map_closureS`, `sclosure_preimage_le`)

#### **4. Proof Logic**

- **Structure of proofs**:
  - **Set-theoretic reasoning**: Most proofs reduce to set equalities via `ext` and `Set.ext`.
  - **Bundled object equality**: Proven via `SetLike.coe_injective` after showing equality of underlying sets.
  - **Induction principles**: `closure_induction` and `closure_induction₂` follow standard induction over constructors (0, 1, elements of `s`, closed under `+`, `*`).
  - **Galois connections**: `map ⊣ comap` used to derive monotonicity, preservation of sup/inf, etc.
  - **Galois insertions**: `closure ⊣ (↑)` used to derive `closure_eq`, `closure_mono`, `map_closureS`, etc.

- **Common proof patterns**:
  - **Membership proofs**: Reduce to `mem_*` lemmas, then use `simp` or `rw`.
  - **Equality of subsemirings**: Show inclusion both ways (`le_antisymm`) or use `Set.ext`.
  - **Universal properties**: Use `closure_le`, `map_le_iff_le_comap`, `gc_map_comap`.
  - **Injective/surjective behavior**: Use `equivMapOfInjective`, `rangeS_top_iff_surjective`, `rangeSRestrict_surjective`.

### Summary

This file formalizes the theory of **bundled subsemirings** in Lean 4, providing:
- A `CompleteLattice` structure on `Subsemiring R`
- `map`/`comap` constructions for ring homomorphisms
- Center and centralizer subsemirings
- Closure operator with induction principles
- Galois connections and insertions
- Product subsemirings and equivalences

It leverages existing structures for submonoids and additive submonoids, and integrates cleanly with Mathlib’s algebraic hierarchy. The design follows the **bundled object pattern**, enabling typeclass inference and smooth reasoning about substructures.
