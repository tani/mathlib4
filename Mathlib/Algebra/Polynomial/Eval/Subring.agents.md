**Technical Metadata Brief: Polynomial Evaluation in Subrings (Lean 4)**

---

### 1. **Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `mapRingHom` | `R →+* S → R[X] →+* S[X]` | Induced ring homomorphism on polynomial rings from a ring homomorphism `f : R →+* S`. |
| `mem_map_rangeS` | `p ∈ (mapRingHom f).rangeS ↔ ∀ n, p.coeff n ∈ f.rangeS` | Characterizes membership in the *subring* generated by the image of `mapRingHom f`: a polynomial lies in the subring iff all its coefficients lie in the subring generated by `f(R)`. |
| `mem_map_range` | `p ∈ (mapRingHom f).range ↔ ∀ n, p.coeff n ∈ f.range` | Analogous to `mem_map_rangeS`, but for the *range* (i.e., actual image) of `mapRingHom f`, assuming `R`, `S` are rings (not just semirings). |

> **Note**: `rangeS` denotes the *subring generated by* a set (or homomorphism’s image), while `range` denotes the *image set* itself.

---

### 2. **Naming Conventions**

- **`mem_…`**: Membership lemmas (e.g., `mem_map_rangeS`, `mem_map_range`).
- **`rangeS` suffix**: Refers to the *subring generated by* a set/image (vs. `range` for plain image).
- **`mapRingHom`**: Standard naming for induced ring homomorphism on polynomial rings.
- **`coeff`**: Standard notation for coefficient function on polynomials.
- **`C`**: Constructor for constant polynomials (`C : R → R[X]`).
- **`X`**: Indeterminate polynomial.

### 4. **Proof Logic**

- **Forward direction (`→`)**:
  - Assume `p = mapRingHom f q` for some `q`.
  - Show each coefficient `p.coeff n = f(q.coeff n)` lies in `f.rangeS` (trivially, as `f(q.coeff n)` is in the image).
- **Reverse direction (`←`)**:
  - Assume all coefficients `p.coeff n ∈ f.rangeS`, i.e., `p.coeff n = f(c_n)` for some `c_n`.
  - Express `p` as `∑ n, C (p.coeff n) * X ^ n`.
  - Use that `mapRingHom f` preserves sums, products, constants, and powers:
    - `mapRingHom f (C c_n * X^n) = C (f c_n) * X^n = p.coeff n * X^n`.
  - Conclude `p` is in the subring generated by `mapRingHom f`’s image.

The proof relies on the **canonical expansion** of polynomials in the basis `{C a * X^n}` and the **homomorphic properties** of `mapRingHom f`.
