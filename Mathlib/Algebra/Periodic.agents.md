### Technical Brief: Periodicity and Antiperiodicity in Lean 4

---

#### **1. Key Definitions & Theorems**

| Name | Type | Purpose |
|------|------|---------|
| `Function.Periodic` | `[Add α] → (α → β) → α → Prop` | Defines `f` as *periodic* with period `c`: `∀ x, f (x + c) = f x`. |
| `Function.Antiperiodic` | `[Add α] [Neg β] → (α → β) → α → Prop` | Defines `f` as *antiperiodic* with antiperiod `c`: `∀ x, f (x + c) = -f x`. |
| `Periodic.funext` | `Periodic f c → (fun x ↦ f (x + c)) = f` | Converts periodicity to function extensionality. |
| `Antiperiodic.periodic` | `[AddMonoid α] [InvolutiveNeg β] → Antiperiodic f c → Periodic f (2 • c)` | Shows antiperiodic ⇒ periodic with doubled period. |
| `Periodic.nsmul`, `Periodic.zsmul`, `Periodic.int_mul` | `Periodic f c → Periodic f (n • c)` / `Periodic f (n * c)` | Closure under natural/integer scalar multiples of period. |
| `Antiperiodic.even_nsmul_periodic`, `Antiperiodic.odd_nsmul_antiperiodic` | `Antiperiodic f c → Periodic f ((2 * n) • c)` / `Antiperiodic f ((2 * n + 1) • c)` | Parity-based behavior of integer multiples of antiperiod. |
| `Antiperiodic.add_zsmul_eq` | `Antiperiodic f c → f (x + n • c) = (n.negOnePow : ℤ) • f x` | Exact formula for shift by integer multiple of antiperiod. |
| `Periodic.lift` | `Periodic f c → (α ⧸ AddSubgroup.zmultiples c) → β` | Lifts a periodic function to the quotient by the cyclic subgroup generated by `c`. |
| `Periodic.not_injective` | `Periodic f c → c ≠ 0 → ¬ Injective f` | Non-injectivity of non-zero-periodic functions over `AddZeroClass`. |
| `Int.fract_periodic` | `Function.Periodic Int.fract 1` | Fractional part function is 1-periodic in a floor ring. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `Periodic.` / `Antiperiodic.`: Module-scoped lemmas.
  - `const_`, `mul_`, `add_`, `sub_`, `neg_`, `smul_`, `div_`: Action on arguments (e.g., `const_add`, `mul_const`, `neg_eq`).
  - `even_`, `odd_`: Parity-sensitive behavior (e.g., `even_nsmul_periodic`, `odd_zsmul_antiperiodic`).
  - `eq`, `sub_eq`, `zsmul_sub_eq`, `int_mul_sub_eq`: Value equalities at specific points.

- **Suffixes**:
  - `_eq`: Equality of function values (e.g., `eq`, `sub_eq`, `zsmul_sub_eq`).
  - `_periodic` / `_antiperiodic`: Closure properties (e.g., `add_periodic`, `mul_antiperiodic`).
  - `₀` (e.g., `const_smul₀`, `const_inv_mul₀`): Variants requiring non-zero assumptions (often `a ≠ 0`).
  - `'` (e.g., `mul_const'`, `div_const'`): Alternative forms (often using `div` instead of `*⁻¹`).

- **Special**:
  - `lift`: Quotient lifting.
  - `map_vadd_*`: Action on additive cosets/submonoids.

---

#### **3. Tactic Stack**

- **Core tactics**:
  - `simp_all`, `simp only`, `simp`: Dominant use for rewriting definitions and simplifying expressions.
  - `rw`: Rewriting with equalities, often after `obtain` or `rcases`.
  - `induction`: Structural induction on `ℕ`, `ℤ`, lists, multisets, finsets.
  - `rcases`: Decomposing existential/universal quantifiers or `Int.even_or_odd'`.
  - `congr_arg`, `funext`: For proving function equality.
  - `by_cases`: Handling `a = 0` vs `a ≠ 0` (especially in division semirings).
  - `exact`, `assumption`, `linarith`: Minor roles.

- **Domain-specific helpers**:
  - `simpa only [...] using`: Cleanly apply lemmas with targeted simplification.
  - `rw [← add_assoc, h, ...]`: Exploit associativity and known periodicity.
  - `mul_cast`, `mod_cast`: For integer/floor ring arithmetic (e.g., `Int.fract_periodic`).

---

#### **4. Proof Logic**

- **Standard pattern**:
  1. **Unfold definition** (`Periodic`/`Antiperiodic`) → `intro x`.
  2. **Rewrite** using `add_assoc`, `sub_eq_add_neg`, `neg_add_cancel`, etc.
  3. **Apply hypothesis** (`h (x + c)`, `h (a • x)`, etc.).
  4. **Simplify** with `simpa`, `simp only`, or `congr_arg`.
  5. For integer/natural multiples: **induction** on `n : ℕ` or `n : ℤ`.

- **Parity arguments**:
  - Use `Int.even_or_odd' n` or `Nat.even_or_odd' n` to split into `2 * k` and `2 * k + 1`.
  - Apply `even_*_periodic` or `odd_*_antiperiodic` accordingly.

- **Quotient lifting**:
  - Use `Quotient.liftOn'` with proof that `a ≈ b ⇒ f a = f b`, via subgroup membership (`AddSubgroup.leftRel_apply`).

- **Archimedean arguments**:
  - Use `existsUnique_zsmul_near_of_pos'`, `existsUnique_add_zsmul_mem_Ico`, etc., to reduce to bounded intervals.
