### Technical Brief: `ArithmeticSubgroups.lean`

---

#### **1. Key Definitions & Theorems**

| Name | Type | Purpose |
|------|------|---------|
| `HasDetPlusMinusOne Γ` | `Prop` | Typeclass asserting all elements of subgroup `Γ ≤ GL(n, R)` have determinant ±1. Ensures slash action is multiplicative. |
| `HasDetOne Γ` | `Prop` | Typeclass asserting all elements of `Γ` have determinant 1. Ensures slash action is ℂ-linear. |
| `𝒮ℒ` | `Subgroup (GL (Fin 2) ℝ)` | Image of `SL(2, ℤ)` under canonical map `mapGL ℝ`. Modular group embedded in `GL(2, ℝ)`. |
| `IsArithmetic 𝒢` | `Prop` | Subgroup `𝒢 ≤ GL(2, ℝ)` is arithmetic iff it is commensurable with `𝒮ℒ`. |
| `Subgroup.adjoinNegOne 𝒢` | `Subgroup (GL n R)` | Subgroup generated by `𝒢` and `-I`. Used to adjoin scalar matrix `-1`. |
| `isArithmetic_iff_finiteIndex` | `IsArithmetic Γ ↔ Γ.FiniteIndex` | Characterizes arithmetic subgroups of `SL(2, ℤ)` as finite-index subgroups. |
| `Subgroup.instIsArithmeticAdjoinNegOne` | `[IsArithmetic 𝒢] → IsArithmetic 𝒢.adjoinNegOne` | Adjoining `-I` preserves arithmeticity. |
| `Subgroup.IsArithmetic.discreteTopology` | `[IsArithmetic 𝒢] → DiscreteTopology 𝒢` | Arithmetic subgroups of `GL(2, ℝ)` are discrete. |
| `discreteSpecialLinearGroupIntRange` | `DiscreteTopology (mapGL ℤ→ℝ).range` | Image of `SL(n, ℤ)` in `GL(n, ℝ)` is discrete. |
| `isClosedEmbedding_mapGLInt` | `IsClosedEmbedding (mapGL ℝ)` | The inclusion `SL(n, ℤ) ↪ GL(n, ℝ)` is a closed embedding. |

  - `adjoinNegOne`: verb + object (`adjoin` + `NegOne`).

  - `instIsArithmeticAdjoinNegOne`, `finiteIndex_comap`: `inst` + target + condition.

#### **4. Proof Logic**

- **Inductive/structural reasoning**: Most proofs proceed by:
  1. **Unfolding definitions** (e.g., `IsArithmetic`, `adjoinNegOne`, `Commensurable`).
  2. **Case analysis** on determinant values (`det = 1` or `-1`) or membership in `𝒢`/`-𝒢`.
  3. **Leveraging typeclasses** (`HasDetPlusMinusOne`, `FiniteIndex`) to propagate properties.
  4. **Using known lemmas** about index, commensurability, and discrete topology (e.g., `relIndex_inf_ne_zero`, `commensurable_adjoinNegOne_self.discreteTopology_iff`).
- **Key logical flow**:
  - To prove `IsArithmetic`, show `Commensurable 𝒢 𝒮ℒ`.
  - To prove `Commensurable`, show both `relIndex 𝒢 𝒮ℒ ≠ 0` and `relIndex 𝒮ℒ 𝒢 ≠ 0`.
  - To prove `DiscreteTopology`, use `commensurable_adjoinNegOne_self.discreteTopology_iff` or `is_commensurable.discreteTopology_iff`.

#### **7. Theory Scope**

This file formalizes foundational aspects of **arithmetic subgroups of `GL(2, ℝ)`**, with emphasis on:

- **Algebraic structure**: Subgroups of `GL(n, R)`, especially those with determinant constraints.
- **Topological structure**: Discreteness, closed embeddings, and topology induced from `ℝ`.
- **Arithmetic geometry**: Connection between `SL(2, ℤ)` and its images in `GL(2, ℝ)`, via commensurability.
- **Modular group theory**: Finite-index subgroups, slash actions, and their algebraic/topological behavior.

It serves as a stepping stone for deeper modular forms or automorphic representation theory formalizations.
