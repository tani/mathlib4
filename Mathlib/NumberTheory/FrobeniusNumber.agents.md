### **4. Proof Logic**

- **Structure**:  
  1. **Goal**: Show `m * n - m - n` is the *largest* non-representable number as `a·m + b·n` (`a, b ∈ ℕ`).  
  2. **Upper bound (non-representability)**:  
     - Prove `m * n - m - n ∉ AddSubmonoid.closure {m, n}`.  
     - Uses contradiction: assume `m * n - m - n = a·m + b·n`, rearrange to get `m·n = (a+1)·m + (b+1)·n`, contradicting coprimality via `cop.mul_add_mul_ne_mul`.  
  3. **Maximality (all larger numbers are representable)**:  
     - For any `k > m·n - m - n`, show `k ∈ AddSubmonoid.closure {m, n}`.  
     - Construct `x` via `chineseRemainder` solving:  
       `x ≡ 0 [MOD m]`, `x ≡ k [MOD n]`.  
     - Show `x ≤ k` (key lemma), then `k - x` is divisible by `n`, and `x` divisible by `m`, so `k = x + (k - x)` is representable.

- **Core Insight**:  
  Leverages the **Chinese Remainder Theorem** (CRT) to construct a multiple of `m` ≤ `k` congruent to `k` mod `n`, enabling decomposition into `m`- and `n`-multiples.
