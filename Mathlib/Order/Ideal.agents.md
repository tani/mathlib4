### **Technical Brief: Order Ideals, Cofinal Sets, and the Rasiowa–Sikorski Lemma**

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `Ideal P` | `[LE P] → Type*` | Type of *ideals* on a preorder `P`: nonempty, downward-closed, upward-directed subsets. |
| `IsIdeal I` | `[LE P] → Set P → Prop` | Predicate expressing that a subset `I ⊆ P` is an ideal. |
| `Ideal.principal p` | `[Preorder P] → P → Ideal P` | Principal ideal generated by `p`: the down-set `↓p = {x | x ≤ p}`. |
| `IsProper I` | `[LE P] → Ideal P → Prop` | Predicate for *proper* ideals: `I ≠ univ`. |
| `IsMaximal I` | `[Preorder P] → Ideal P → Prop` | Predicate for *maximal* proper ideals: maximal in the poset of proper ideals under inclusion. |
| `Cofinal P` | `[Preorder P] → Type*` | Type of *cofinal* subsets of `P`: subsets containing arbitrarily large elements (dual to dense sets in forcing). |
| `idealOfCofinals p 𝒟` | `[Preorder P] → p : P → ι : Type* [Encodable ι] → (ι → Cofinal P) → Ideal P` | Constructs an ideal containing `p` and meeting every cofinal set in a countable family `𝒟`. This is the **Rasiowa–Sikorski lemma**. |
| `sequenceOfCofinals p 𝒟` | `[Preorder P] → p : P → ι : Type* [Encodable ι] → (ι → Cofinal P) → ℕ → P` | Monotone sequence intersecting each cofinal set in `𝒟`, used to define `idealOfCofinals`. |
| `IsCoatom I` | `[Preorder P] → Ideal P → Prop` | Atom below top: `I < J ⇒ J = ⊤`. Equivalent to `IsMaximal I` in directed nonempty preorders. |

**Key Theorems**:
- `isMaximal_iff_isCoatom`: In a directed, nonempty preorder, maximal ideals = coatoms.
- `mem_idealOfCofinals`: `p ∈ idealOfCofinals p 𝒟`.
- `cofinal_meets_idealOfCofinals`: For all `i`, `idealOfCofinals p 𝒟 ∩ 𝒟 i ≠ ∅`.
- `sup_mem_iff`: In a semilattice sup, `x ⊔ y ∈ I ↔ x ∈ I ∧ y ∈ I`.
- `isIdeal_sUnion_of_directedOn`: Directed union of ideals is an ideal.
