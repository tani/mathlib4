### Technical Metadata Brief: `Mathlib.Topology.Hom.CompactOpen`

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `compactOpen` | `TopologicalSpace C(X, Y)` | Defines the **compact-open topology** on the space of continuous maps `C(X, Y)` as the topology generated by sets `{f | MapsTo f K U}` for compact `K ⊆ X`, open `U ⊆ Y`. |
| `coev` | `Y → C(X, Y × X)` | **Coevaluation map**, sending `y ↦ (x ↦ (y, x))`. Always continuous. |
| `curry` | `C(X × Y, Z) → C(X, C(Y, Z))` | **Currying map**, converting a map on a product into a curried function. Continuous if `X × Y` is locally compact. |
| `uncurry` | `C(X, C(Y, Z)) → C(X × Y, Z)` | **Uncurrying map**, reversing currying. Exists and is continuous if `Y` (and `X`) is locally compact. |
| `Homeomorph.curry` | `C(X × Y, Z) ≃ₜ C(X, C(Y, Z))` | **Currying homeomorphism**, exists when both `X` and `Y` are locally compact. |
| `continuous_comp'` | `Continuous fun ⟨f, g⟩ ↦ g ∘ f` | Composition is continuous `C(X, Y) × C(Y, Z) → C(X, Z)` if `Y` is locally compact (Bourbaki Prop. 9). |
| `continuous_coev` | `Continuous (coev X Y)` | Coevaluation is always continuous. |
| `continuous_curry` | `Continuous (curry : C(X × Y, Z) → C(X, C(Y, Z)))` | Currying is continuous if `X × Y` is locally compact. |
| `continuous_uncurry` | `Continuous (uncurry : C(X, C(Y, Z)) → C(X × Y, Z))` | Uncurrying is continuous if `X`, `Y` are locally compact. |
| `continuous_restrict` | `Continuous (F ↦ F.restrict s)` | Restriction to a subspace is continuous. |
| `compactOpen_eq_iInf_induced` | Equality of compact-open topology with infimum over compact subsets | Shows compact-open topology is the coarsest making all restrictions `C(X, Y) → C(K, Y)` continuous for compact `K`. |
| `tendsto_compactOpen_iff_forall` | Convergence in compact-open topology ⇔ convergence on all compact subsets | Characterizes convergence in the compact-open topology. |
| `Homeomorph.arrowCongr` | `X ≃ₜ Z → Y ≃ₜ T → C(X, Y) ≃ₜ C(Z, T)` | Induced homeomorphism on function spaces from homeomorphisms of domains/codomains. |
| `continuous_postcomp`, `continuous_precomp` | `C(X, Y) → C(X, Z)` and `C(Y, Z) → C(X, Z)` continuity | Functoriality of `C(-, Z)` and `C(X, -)` in the category of topological spaces. |
| `isEmbedding_postcomp`, `isInducing_postcomp` | Preservation of embeddings/inducing maps under postcomposition | Structural stability of function space constructions. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `continuous_`: asserts continuity of a map (e.g., `continuous_comp'`, `continuous_coev`, `continuous_curry`).
  - `isEmbedding_`, `isInducing_`: properties of maps (e.g., `isEmbedding_postcomp`).
  - `coev`, `curry`, `uncurry`: standard categorical operations.
  - `compRight_`, `arrowCongr`: constructions involving composition or congruence.

- **Suffixes**:
  - `_postcomp`, `_precomp`: indicate post- or pre-composition functors.
  - `_restrict`: restriction maps.
  - `_compCM`: composition of continuous maps as a binary operation (e.g., `compCM` for “continuous map composition”).

- **Other patterns**:
  - `setOf_mapsTo`: set of functions mapping a subset `K` into `U`.
  - `nhds_`, `tendsto_`: neighborhood/tendsto characterizations.
  - `coe_`, `coeFun`: coercion-related lemmas (e.g., `specializes_coe`, `inseparable_coe`).

#### **4. Proof Logic**

- **Structure of proofs**:
  - **Continuity proofs** often reduce to checking preimages of subbasic opens `{f | MapsTo f K U}` are open, using `continuous_compactOpen`.
  - **Convergence/tendsto proofs** use `tendsto_nhds_compactOpen`, reducing to uniform behavior on compact sets.
  - **Homeomorphism proofs** involve constructing inverse maps (`curry`/`uncurry`) and verifying continuity of both directions.
  - **Functoriality proofs** (e.g., `continuous_postcomp`, `continuous_precomp`) use `continuous_compactOpen` and properties of `MapsTo`.
  - **Topological separation axioms** (e.g., `T0Space`, `T1Space`) are lifted from `Y` to `C(X, Y)` via `specializes_coe`, `inseparable_coe`, and injectivity of coercion.

- **Common proof patterns**:
  - **Induction on compact sets** (e.g., using `isCompact_iff_isCompact_univ`).
  - **Tube lemma variants** (e.g., `generalized_tube_lemma` in `continuous_coev`).
  - **Gluing local limits** (e.g., `liftCover'` in `exists_tendsto_compactOpen_iff_forall`).
  - **Filter-based arguments** using `tendsto_compactOpen_iff_forall` and `compactOpen_eq_iInf_induced`.

**Domain scope**:  
This module formalizes foundational results in **function space topology**, especially the **compact-open topology**, with emphasis on:
- Functoriality (`C(X, -)`, `C(-, Z)`),
- Currying/uncurrying and exponential laws,
- Continuity of composition and evaluation,
- Topological separation axioms on function spaces,
- Convergence and restriction properties.

It serves as a core component for higher-level developments in homotopy theory, categorical topology, and analysis on function spaces.
