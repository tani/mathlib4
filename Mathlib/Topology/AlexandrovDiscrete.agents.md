### Technical Metadata Brief: Alexandrov-Discrete Spaces in Lean 4 (Mathlib)

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `AlexandrovDiscrete` | `class AlexandrovDiscrete (α : Type*) [TopologicalSpace α] : Prop` | Typeclass stating that arbitrary intersections of open sets are open (i.e., the topology is *finitely generated*). |
| `isOpen_sInter` | `∀ S : Set (Set α), (∀ s ∈ S, IsOpen s) → IsOpen (⋂₀ S)` | Core property: intersection of any family of open sets is open. |
| `exterior` | `exterior s := ⋂₀ {u | IsOpen u ∧ s ⊆ u}` | Minimal open neighborhood of a set `s`; defined as the intersection of all open supersets of `s`. |
| `exterior_def` | `exterior s = ⋂₀ {u | IsOpen u ∧ s ⊆ u}` | Definition lemma for `exterior`. |
| `isOpen_exterior` | `IsOpen (exterior s)` | `exterior s` is open (by definition of intersection of opens). |
| `exterior_mem_nhdsSet` | `exterior s ∈ 𝓝ˢ s` | `exterior s` is a neighborhood of `s`. |
| `exterior_eq_iff_isOpen` | `exterior s = s ↔ IsOpen s` | A set equals its exterior iff it is open. |
| `exterior_subset_iff` | `exterior s ⊆ t ↔ ∃ U, IsOpen U ∧ s ⊆ U ∧ U ⊆ t` | Characterization of when the exterior of `s` lies inside `t`. |
| `gc_exterior_interior` | `GaloisConnection exterior interior` | `exterior` and `interior` form a Galois connection (contravariant adjunction). |
| `principal_exterior` | `𝓟 (exterior s) = 𝓝ˢ s` | The principal filter of `exterior s` equals the neighborhood filter of `s`. |
| `isOpen_iff_forall_specializes` | `IsOpen s ↔ ∀ x y, x ⤳ y → y ∈ s → x ∈ s` | Openness ⇔ upward-closed under the *specialization preorder* `⤳`. |
| `alexandrovDiscrete_coinduced` | `@AlexandrovDiscrete β (coinduced f ‹_›)` | Coinduced topology along any map from an Alexandrov space is Alexandrov. |
| `alexandrovDiscrete_iSup` | `@AlexandrovDiscrete α (⨆ i, t i)` | Arbitrary supremum (i.e., join) of Alexandrov topologies is Alexandrov. |
| `instance AlexandrovDiscrete.toFirstCountable` | `FirstCountableTopology α` | Every Alexandrov space is first-countable (generated by `exterior {a}`). |
| `instance AlexandrovDiscrete.toLocallyCompactSpace` | `LocallyCompactSpace α` | Every Alexandrov space is locally compact (via `exterior {a}`). |

#### **2. Naming Conventions**

- **Prefixes**:
  - `exterior_`: properties of the *exterior* operator (e.g., `exterior_mem_nhdsSet`, `exterior_subset_iff`).
  - `isOpen_`, `isClosed_`, `isClopen_`: closure properties under arbitrary unions/intersections.
  - `alexandrovDiscrete_`: constructions/instances preserving Alexandrov-ness (e.g., `alexandrovDiscrete_coinduced`, `alexandrovDiscrete_iSup`).
- **Suffixes**:
  - `_sInter`, `_iInter`: for arbitrary (`sInter`) vs indexed (`iInter`) intersections.
  - `_sUnion`, `_iUnion`: for unions.
  - `_iff_`: biconditional characterizations (e.g., `exterior_eq_iff_isOpen`).
- **Operator names**:
  - `exterior`: minimal open neighborhood (analogous to `interior`).
  - `interior`, `closure`: standard topological operators, but with simplified behavior (e.g., `interior_iInter`, `closure_iUnion`).

#### **3. Tactic Stack**

Frequent tactics used in proofs:
- `simp_rw`: for rewriting using definitional equalities (e.g., `sInter_eq_biInter`, `preimage_iInter`).
- `simp only [...]`: targeted simplification (e.g., removing `compl`, `preimage`, or filter definitions).
- `exact`, `refine`, `assumption`: for straightforward proof steps.
- `intros`, `cases`, `choose`: for destructuring quantifiers and existential witnesses.
- `apply`, `apply_fun`, `convert`: for applying lemmas or congruences.
- `rw [← ...]`: for rewriting using complements (e.g., `← interior_compl`).
- `antisymm'`: for proving equality of sets via mutual inclusion.
- `countable_singleton _`: to prove countability of singletons (used in `FirstCountableTopology` instance).

#### **4. Proof Logic**

- **Inductive/structural style**: Most proofs follow standard topological reasoning:
  - Use `isOpen_sInter` to reduce arbitrary intersections to open sets.
  - Leverage `exterior` as a *canonical* open neighborhood (via its minimality).
  - Use Galois connections (`gc_exterior_interior`) to transfer properties between `exterior` and `interior`.
- **Common pattern**:
  1. Unfold definitions (`exterior`, `interior`, `closure`, `nhdsSet`, etc.).
  2. Apply `isOpen_sInter` / `isClosed_sUnion` to handle arbitrary operations.
  3. Use filter lemmas (`nhdsSet_eq`, `mem_nhdsSet_iff_exists`) to relate neighborhoods.
  4. For preorder-related lemmas (`isOpen_iff_forall_specializes`), use `mem_exterior_iff_specializes`.
- **Instance proofs** (e.g., `alexandrovDiscrete_coinduced`, `Sum.instAlexandrovDiscrete`) often:
  - Reduce to `isOpen_sInter`.
  - Use `preimage_sInter`, `isOpen_coinduced`, or `isOpen_iSup_iff`.

### Summary

This module formalizes **Alexandrov-discrete spaces** — topological spaces where arbitrary intersections of open sets are open — and develops their core theory, including:
- The *exterior* operator as the minimal open neighborhood.
- Equivalence with the *Alexandrov topology* induced by the specialization preorder.
- Closure under many constructions: subspaces, quotients, sums, sigma types, coinduced topologies, and arbitrary suprema.
- Consequences: first-countability, local compactness.

The formalization is highly structured, leveraging Lean’s typeclass inference and filter machinery, with a focus on duality (`exterior` ↔ `interior`) and preorder semantics.
