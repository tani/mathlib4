#### **2. Naming Conventions**

- **Predicates**: `IsSubgroup`, `IsAddSubgroup`, `IsNormalSubgroup`, `IsNormalAddSubgroup`  
  → Prefix `Is_` indicates *unbundled* predicates (as opposed to bundled types like `Subgroup G`).

- **Constructors / Helpers**:  
  - `of_*`: e.g., `of_div`, `of_sub`, `of_normal` — construct bundled objects from unbundled data.  
  - `closure_*`: e.g., `closure`, `normalClosure`, `center`, `normalizer` — define canonical substructures.  
  - `mem_*`: e.g., `mem_ker`, `mem_center`, `mem_normalizer` — membership characterizations.  
  - `_*_iff`: e.g., `inv_mem_iff`, `injective_iff_trivial_ker`, `normalClosure_subset_iff` — equivalence lemmas.

- **Conversion between additive/multiplicative**:  
  - `Additive.*`, `Multiplicative.*`: e.g., `Additive.isAddSubgroup`, `Multiplicative.isSubgroup_iff`.  
  - `to_additive` attribute used to auto-generate additive versions.

- **Set-theoretic operations**:  
  - `inter`, `iInter`, `iUnion`, `subset_*`, `mono` — standard lattice operations on subgroups.

#### **4. Proof Logic & Strategy**

- **Inductive definitions**:  
  Proofs about `InClosure` (e.g., `closure`, `normalClosure`) use *induction on the inductive type*, with cases for:
  - `basic` (membership in generating set),
  - `one` / `zero`,
  - `inv` / `neg`,
  - `mul` / `add`.

- **Equational reasoning**:  
  Many proofs (e.g., `center_normal`, `normalClosure.is_normal`) use *calc* blocks to chain equalities/implications, especially for conjugation/closure properties.

- **Bundled ↔ unbundled translations**:  
  Theorems like `Additive.isAddSubgroup_iff`, `Multiplicative.isSubgroup_iff`, `Subgroup.isSubgroup` provide bidirectional bridges between unbundled predicates and bundled subgroups.

- **Homomorphism lemmas**:  
  Follow a pattern:  
  1. Use `hf.map_*` to translate operations.  
  2. Apply subgroup closure properties (`mul_mem`, `inv_mem`, etc.).  
  3. Use `mem_ker` to reduce to `f(x) = 1`.

- **Normality proofs**:  
  Use `normal` field of `IsNormalSubgroup` and manipulate conjugates (`g * n * g⁻¹`).  
  E.g., `mem_norm_comm` shows `a * b ∈ s ↔ b * a ∈ s` for normal `s`.

- **Closure minimality**:  
  `closure_subset`, `normalClosure_subset` use induction on `InClosure` to show minimality.

### Summary

This file provides **unbundled** subgroup theory (predicates on subsets), now superseded by the **bundled** `Subgroup G` / `AddSubgroup A` approach. It remains useful for understanding legacy code or low-level subgroup constructions, but modern mathlib usage should avoid direct imports. Key themes:  
- Equivalence between additive/multiplicative via `Additive`/`Multiplicative` wrappers.  
- Closure operators (`closure`, `normalClosure`) defined inductively.  
- Homomorphism properties (kernel, image, injectivity) tied to subgroup structure.  
- Normality characterized via conjugation closure.
