#### 2. **Naming Conventions**

- **Predicates**: `Is*` prefix (`IsSubmonoid`, `IsAddSubmonoid`) — indicates *unbundled* structure.
- **Bundled types**: `Submonoid`, `AddSubmonoid` — bundled versions (preferred).
- **Operations**:
  - `closure` — generated submonoid.
  - `powers`, `InClosure` — related to generation by single element or set.
  - `of` — bundling constructor (`Submonoid.of`).
- **Properties**:
  - `*_mem` suffix — membership in submonoid (e.g., `one_mem`, `mul_mem`, `zero_mem`, `add_mem`).
  - `*_subset` — subset relations (e.g., `powers_subset`, `subset_closure`).
  - `*_mono` — monotonicity (e.g., `closure_mono`).
  - `*_iff` — equivalence statements (e.g., `Multiplicative.isSubmonoid_iff`).
- **Conversion lemmas**:
  - `Additive.*`, `Multiplicative.*` — relate additive/multiplicative versions via `Additive`/`Multiplicative` newtypes.

#### 3. **Tactic Stack**

Frequent tactics used in proofs:

- `constructor` — for structure/intro/apply on `Prop`-valued definitions.
- `simp` / `simp only` — simplification, especially with `pow_zero`, `pow_succ`, `pow_add`, `mul_one`, etc.
- `rw` — rewriting using equalities or definitions.
- `exact`, `assumption`, `intro`, `cases` — basic proof automation.
- `induction` / `induction'` — structural induction on inductive predicates (`InClosure`), lists, multisets.
- `solve_by_elim` — for quick proof search using intro/apply.
- `rcases`, `obtain` — destructuring existential/and hypotheses.
- `set_tac` (e.g., `Set.mem_iInter.2`, `Set.mem_iUnion.2`) — set membership reasoning.
- `le_antisymm` — proving equality of sets via double inclusion.
- `funext`, `ext` — extensionality for functions/sets (used implicitly via `simp`/`rw`).
- `ring`, `abel` — not used here (more common in additive/commutative algebra files).
- `aesop` — not present; this file uses more explicit tactics.

#### 4. **Proof Logic**

- **Inductive definitions**: Proofs about `InClosure` use induction on its constructors (`basic`, `one`, `mul`).
- **Set equality**: Often shown via `le_antisymm` (double inclusion), especially for `closure_singleton`, `image_closure`, `mem_closure_union_iff`.
- **Closure properties**: Prove `IsSubmonoid (intersection)` by showing `one_mem` and `mul_mem` hold pointwise.
- **Directed unions**: Use nonemptiness and directedness to find a common superset containing both elements.
- **Image/preimage stability**: Use homomorphism properties (`map_one`, `map_mul`) and closure of target set.
- **List/multiset/finset products**: Prove by induction on list structure; use `list_prod_mem` as base for `multiset_prod_mem` and `finset_prod_mem`.
- **Conversion lemmas**: Use `Additive`/`Multiplicative` type class instances to transfer structure between additive and multiplicative settings.
