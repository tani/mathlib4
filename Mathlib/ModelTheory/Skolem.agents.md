### Technical Brief: Skolem Functions and Downward Löwenheim–Skolem in Lean 4 (Mathlib)

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `skolem₁` | `Language.{u, v} → Language` | Constructs a new language `L.skolem₁` whose function symbols of arity `n` correspond to bounded formulas of arity `n+1` in `L`. Represents the first step toward Skolemization. |
| `skolem₁Structure` | `[L.Structure M] → L.skolem₁.Structure M` | Interprets each Skolem function symbol as a choice-based witness: `φ(x, a) ⇒ a = εa. φ(x, a)`. Uses `Classical.epsilon`. |
| `skolem₁_reduct_isElementary` | `(S : (L.sum L.skolem₁).Substructure M) → (LHom.sumInl.substructureReduct S).IsElementary` | Shows that any `(L + L.skolem₁)`-substructure, when viewed as an `L`-substructure via the left injection, is *elementary*. |
| `elementarySkolem₁Reduct` | `(S : (L.sum L.skolem₁).Substructure M) → L.ElementarySubstructure M` | Forgets the Skolem functions, yielding an elementary `L`-substructure. |
| `exists_elementarySubstructure_card_eq` | `(s : Set M) → (κ : Cardinal) → ... → ∃ S : L.ElementarySubstructure M, s ⊆ S ∧ #S = κ` | **Downward Löwenheim–Skolem Theorem**: For infinite `κ` satisfying `max(#s, L.card) ≤ κ ≤ #M`, there exists an elementary substructure of size `κ` containing `s`. |

---

#### **2. Naming Conventions**

- **Prefixes**:
  - `skolem₁_`: Relates to the first-order Skolemization step (e.g., `skolem₁`, `skolem₁Structure`, `skolem₁_reduct_isElementary`).
  - `elementarySkolem₁Reduct`: Combines “elementary” and “reduct” to indicate passage to an elementary substructure via reduct.
  - `card_`, `lift_`, `mk_`: Standard cardinal arithmetic helpers (`card_functions_sum_skolem₁`, `lift_id'`, `mk_sigma`, `mk_image_eq_lift`).
- **Suffixes**:
  - `_structure`: Defines a structure instance (e.g., `skolem₁Structure`).
  - `_reduct`: Indicates a forgetful reduct of structure (e.g., `substructureReduct`, `skolem₁_reduct_isElementary`).
  - `_elementary`: Pertains to elementary embeddings/substructures (e.g., `isElementary`, `elementarySkolem₁Reduct`).

#### **4. Proof Logic**

The proof of `exists_elementarySubstructure_card_eq` follows this logical flow:

1. **Reduction to universe-lifted cardinals**:
   - Use `Cardinal.le_mk_iff_exists_set` to pull back `M` to a universe-lifted set `s'`.
   - Rewrite hypotheses in terms of `s'` to simplify cardinal comparisons.

2. **Construct candidate substructure**:
   - Take the `(L + L.skolem₁)`-substructure generated by `s ∪ ulift '' s'`.
   - Apply `elementarySkolem₁Reduct` to get an `L`-elementary substructure.

3. **Cardinality analysis**:
   - Show lower bound: `κ ≤ #S` via `mk_le_mk_of_subset` (since `s ∪ ... ⊆ S`).
   - Show upper bound: `#S ≤ κ` using:
     - `lift_card_closure_le` (bound on closure size),
     - `card_functions_sum_skolem₁_le` (bound on added Skolem functions),
     - Cardinal arithmetic (`add_eq_max`, `max_le_iff`, `lift_*` lemmas).

4. **Final equality**:
   - Combine bounds with `le_antisymm`.
   - Use `lift_inj` to lift back to original universe.

Key insight: Skolem functions allow *definable witnesses*, so closure under Skolem terms yields an elementary substructure.

#### **Summary**

This file formalizes the *Downward Löwenheim–Skolem theorem* using Skolemization as a tool. It introduces `skolem₁`, constructs Skolem structures via choice, and proves that substructures of the Skolemized language are elementary in the original language. The main theorem ensures existence of elementary substructures of any intermediate infinite cardinality. The proofs rely heavily on careful cardinal arithmetic and universe management—hallmarks of modern Lean formalization in Mathlib.
