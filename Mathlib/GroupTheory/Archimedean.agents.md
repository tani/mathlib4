### Technical Brief: Archimedean Ordered Groups in Lean 4

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `Archimedean` | `class Archimedean (α) [OrderedAddCommMonoid α] : Prop := (arch : ∀ (x : α) {y}, 0 < y → ∃ n : ℕ, x ≤ n • y)` | Defines the Archimedean property for additive ordered monoids. |
| `MulArchimedean` | `class MulArchimedean (α) [OrderedCommGroup α] : Prop` | Multiplicative counterpart of `Archimedean`, used for multiplicative groups. |
| `Subgroup.cyclic_of_min` | `{H : Subgroup G} → {a : G} → IsLeast {g | g ∈ H ∧ 1 < g} a → H = closure {a}` | If a subgroup `H` has a minimal element >1, then `H` is cyclic generated by that element. |
| `Subgroup.exists_isLeast_one_lt` | `(H : Subgroup G) → H ≠ ⊥ → 1 < a → Disjoint H (Ioo 1 a) → ∃ b, IsLeast {g | g ∈ H ∧ 1 < g} b` | Under disjointness from `Ioo 1 a`, existence of minimal element >1 in `H`. |
| `Subgroup.cyclic_of_isolated_one` | `(H : Subgroup G) → 1 < a → Disjoint H (Ioo 1 a) → ∃ b, H = closure {b}` | If `H` avoids an interval `(1, a)`, then `H` is cyclic. |
| `Int.subgroup_cyclic` | `(H : AddSubgroup ℤ) → ∃ a, H = AddSubgroup.closure {a}` | Every additive subgroup of `ℤ` is cyclic. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `is_`: e.g., `isLeast`, `isBounded`, `isClosed` — used for properties of elements or sets.
  - `cyclic_of_`: e.g., `cyclic_of_min`, `cyclic_of_isolated_one` — indicates a cyclic structure result derived from a condition.
  - `exists_`: e.g., `exists_isLeast_one_lt`, `existsUnique_zpow_near_of_one_lt` — existence lemmas.

- **Suffixes**:
  - `_of_`: e.g., `cyclic_of_min`, `cyclic_of_isolated_one` — condition-based naming.
  - `_mem_`: e.g., `zpow_mem`, `div_mem`, `add_mem` — membership lemmas for subgroup operations.

- **Interval notation**:
  - `Ioo`, `Ioc`, `Icc`, `Ico`: standard interval types from `Set`.
  - `Ioo 1 a` = `{x | 1 < x ∧ x < a}`; `Ioc a b` = `{x | a ≤ x ∧ x < b}`.

- **Multiplicative vs additive**:
  - Multiplicative: `1`, `*`, `^`, `div`, `zpow`.
  - Additive: `0`, `+`, `•`, `sub`, `zsmul`.
  - `to_additive` attribute used to derive additive versions of multiplicative lemmas.

#### **3. Tactic Stack**

- **Core tactics**:
  - `simp`, `simp_rw`, `aesop`, `linarith`, `ring`, `omega`, `rcases`, `cases'`, `by_contra`, `contradiction`, `exact`, `refine`, `apply`, `intro`, `obtain`, `have`, `show`, `calc`.

- **Specialized tactics**:
  - `lift m to ℕ`: used to convert integer index to natural number when exponentiation is involved.
  - `by_contra`: for contradiction proofs.
  - `disjoint_left.1`: for reasoning about disjoint sets.
  - `mem_closure_singleton`: to conclude membership in a cyclic subgroup.

- **Order & Archimedean reasoning**:
  - `pow_le_pow_right'`, `zpow_lt_zpow_iff_right`, `div_lt_iff_lt_mul'`, `mul_lt_mul_right'`: for manipulating inequalities in ordered groups.

#### **4. Proof Logic**

- **General proof strategy**:
  - **Step 1**: Use Archimedean property or discreteness (e.g., disjointness from an interval) to locate a minimal positive element.
  - **Step 2**: Show that any element of the subgroup can be approximated by powers of this minimal element.
  - **Step 3**: Use uniqueness or minimality to force equality (e.g., via `div_eq_one`).
  - **Step 4**: Conclude cyclicity via `closure_le` and `le_closure`.

- **Typical flow**:
  - Induction or case analysis on subgroup triviality (`bot_or_exists_ne_one`).
  - Use of `existsUnique_zpow_near_of_one_lt` (from `Mathlib.Analysis.Normed.Group.Basic` or similar) to get near-integer exponent approximations.
  - Contradiction arguments to eliminate non-minimal elements.
  - For `Int.subgroup_cyclic`: reduce to additive version via `AddSubgroup.cyclic_of_isolated_zero`, using `Ioo 0 1 = ∅`.
