### **4. Proof Logic**

- **Structure of Schreier’s Lemma proofs**:
  1. Define Schreier set `U = (R * S).image (g ↦ g * r(g)⁻¹)`
  2. Show `closure U ≤ H` (easy inclusion)
  3. Show `closure U * R = G` using closure induction over generating set `S`
  4. Conclude `closure U = H` by uniqueness of coset representatives (since `H * r = H` iff `r = 1`)

- **Finite generation argument**:
  - Use `exists_finset_card_le_mul` to construct finite generating set for `H`
  - Bound size via `R.card = index(H)` and `S.card = rank(G)`
  - Apply `fg_of_index_ne_zero` to get `Group.FG H`

- **Schur’s Theorem**:
  - Reduce to finite-index center case via `by_cases`
  - Use subgroup lattice: `Z(G) ∩ G' ≤ G'`
  - Apply Schreier’s Lemma to bound `rank(Z(G) ∩ G')`
  - Use transfer homomorphism to show `g^[G:Z(G)] = 1` for `g ∈ Z(G) ∩ G'`
  - Combine divisibility and rank bounds to get final inequality
