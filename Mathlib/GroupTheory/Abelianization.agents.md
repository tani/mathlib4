### Technical Metadata Brief: Abelianization in Lean 4 (Mathlib)

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `commutator G` | `Subgroup G` | The **commutator subgroup** of `G`, defined as `⁅(⊤ : Subgroup G), ⊤⁆`, i.e., the subgroup generated by all commutators `[p, q] = p * q * p⁻¹ * q⁻¹`. |
| `Abelianization G` | `Type u` | The **abelianization** of `G`, defined as the quotient group `G ⧸ commutator G`. |
| `of : G →* Abelianization G` | `MonoidHom G (Abelianization G)` | The canonical projection (surjective group homomorphism) from `G` to its abelianization. |
| `lift f` | `(G →* A) ≃ (Abelianization G →* A)` for `A` abelian | Universal property: lifts any homomorphism `f : G → A` (with `A` abelian) uniquely through `of`. |
| `map f : Abelianization G →* Abelianization H` | `MonoidHom (Abelianization G) (Abelianization H)` | Functoriality: induced map on abelianizations from `f : G →* H`. |
| `MulEquiv.abelianizationCongr e` | `Abelianization G ≃* Abelianization H` | If `G ≃* H`, then their abelianizations are isomorphic. |
| `Abelianization.equivOfComm` | `H ≃* Abelianization H` (for `H` abelian) | An abelian group is canonically isomorphic to its abelianization. |
| `commutator_subset_ker` | `commutator G ≤ f.ker` | Key lemma: the commutator subgroup lies in the kernel of any map to an abelian group. |
| `ker_of` | `of.ker = commutator G` | Kernel of the projection `of` is exactly the commutator subgroup. |
| `lift.unique` | Uniqueness of lift | Any map factoring `f` through `of` must equal `lift f`. |
| `commutator_characteristic` | `(commutator G).Characteristic` | The commutator subgroup is characteristic (invariant under all automorphisms). |
| `commutator_eq_closure` / `commutator_eq_normalClosure` | Equality lemmas | Shows `commutator G` equals the subgroup/normal closure of `commutatorSet G`. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `commutator_`: for properties/definitions related to the commutator subgroup (`commutator`, `commutator_def`, `commutator_eq_closure`, etc.).
  - `abelianization_`: for constructions involving abelianization (`abelianizationCongr`, `equivOfComm`, etc.).
  - `of`: canonical projection (`of`, `mk_eq_of`, `lift.of`, `map_of`).
  - `lift`: universal property (`lift`, `lift.unique`, `lift_of`).
  - `map`: functorial action (`map`, `map_id`, `map_comp`, `map_map_apply`).

- **Suffixes**:
  - `_def`: definition simplification lemmas (`commutator_def`, `lift.of`).
  - `_eq_`: equality lemmas (`commutator_eq_closure`, `abelianizationCongr_symm`).
  - `_le_`: subgroup inclusion (`commutator_centralizer_commutator_le_center`).
  - `_congr`: equivalence/isomorphism lemmas (`abelianizationCongr`, `abelianizationCongr_trans`).
  - `_fg`, `_finite`: finiteness properties (`Group.FG`, `Finite`, `Fintype`).

#### **4. Proof Logic**

- **Structure**: Modular, with clear sections (`lift`, `Map`, `AbelianizationCongr`, etc.).
- **Common proof patterns**:
  - **Quotient induction**: Proving properties on `Abelianization G` by lifting to `G`.
  - **Universal property**: Using `lift` to reduce problems about maps out of `Abelianization G` to maps out of `G`.
  - **Functoriality**: Proving `map_id`, `map_comp` via `hom_ext` (extensionality for homs).
  - **Characteristic/normality**: Leveraging `Subgroup.commutator_normal`, `commutator_characteristic`.
  - **Finiteness arguments**: Using `closure_finite_fg`, `rank_closure_finite_le_nat_card`, and cardinality bounds.
  - **Set-theoretic constructions**: For `commutatorRepresentatives`, using `Set.range`, `subtype_injective`, and cardinality congruences.

- **Induction style**: Mostly structural (e.g., on elements of `Abelianization G` via `Quotient.induction_on`), not inductive on natural numbers.
