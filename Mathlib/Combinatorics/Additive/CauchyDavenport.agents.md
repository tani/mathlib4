#### **4. Proof Logic**

- **Inductive strategy**:
  - Induction on `(s, t)` via `wellFoundedOn_devosMulRel`.
  - Base cases handled by simplification (`#t < #s`, singleton `s`).
  - Recursive step:
    1. Find `g ≠ 1` such that `s ∩ g • s ≠ ∅`.
    2. If `g • s = s`, then `s` contains a nontrivial subgroup ⇒ bound follows from minimality of `minOrder`.
    3. Else, apply **e-transforms**:
       - Define `s' = s ∩ g • s`, `t' = t ∪ g⁻¹ • t`
       - Define `s'' = s ∪ g • s`, `t'' = t ∩ g⁻¹ • t`
       - Show one of `(s', t')` or `(s'', t'')` is strictly smaller under `DevosMulRel`.
       - Apply induction hypothesis to that pair.
       - Use inequalities on cardinals (`aux1`, `aux2`) to lift bound back to original `(s, t)`.

- **Linear order case**:
  - Avoids group theory entirely.
  - Uses extremal elements: `s.max' hs`, `t.min' ht`.
  - Proves intersection of two "extremal products" is a singleton.
  - Applies inclusion-exclusion for cardinalities.

### Summary

This file formalizes a deep result in additive combinatorics — the Cauchy-Davenport theorem — in three major settings:
1. **General groups** (via DeVos’s e-transform induction),
2. **Torsion-free groups** (simpler bound),
3. **Linearly ordered cancellative semigroups** (elementary extremal argument).

It showcases advanced Lean techniques: well-founded recursion over structured pairs, careful case analysis, and interplay between set-theoretic and algebraic properties. The naming and structure reflect Lean’s emphasis on modularity, reuse (via `to_additive`), and formal precision.
