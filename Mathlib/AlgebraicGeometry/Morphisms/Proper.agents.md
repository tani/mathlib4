#### **2. Naming Conventions**

- **Prefixes / Suffixes**:
  - `is_` prefix: Standard for morphism properties (`IsSeparated`, `IsProper`, `IsClosedImmersion`, etc.).
  - `UniversallyClosed`, `LocallyOfFiniteType`: Composite names using camelCase; no special suffix.
  - `isProper_eq`: Uses `is_` + property name + `_eq` for equality lemmas linking class and lattice-theoretic view.
  - `isProper_iff`: Standard `iff` suffix for `mk_iff`-generated equivalences.
