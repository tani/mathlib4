#### **2. Naming Conventions**

- **Prefixes**:
  - `awayMapₐ`: Refers to canonical maps from graded ring to away-localization (graded localization at multiplicative set generated by homogeneous element).
  - `lift_`: Indicates use of universal property of tensor product (i.e., `Algebra.TensorProduct.lift`).
  - `pullback...`: Refers to constructions involving pullbacks in Sch (e.g., `pullbackAwayιIso`, `pullbackDiagonalMapIdIso`).
  - `Spec.map`, `Spec.of`, `Spec.map_comp`: Standard scheme morphism operations.

- **Suffixes**:
  - `_surjective`: Denotes a surjectivity result.
  - `_Iso`: Denotes an isomorphism (e.g., `pullbackAwayιIso`, `pullbackSpecIso`).
  - `_hom`, `_inv`: For morphism components of isomorphisms.

- **Other patterns**:
  - `NumDenSameDeg`: Type of pairs `(num, den)` with equal degree in graded localization.
  - `mk_surjective`: Use of surjectivity of `mk` map in localization.

#### **4. Proof Logic**

- **Overall Strategy**:
  - Show `Proj 𝒜 → Spec (𝒜 0)` is separated by verifying the diagonal morphism is a **closed immersion**.
  - Use the criterion: a morphism is separated if its diagonal is a closed immersion.
  - Reduce to checking that for an affine open cover `{U_i}`, the pullbacks `U_i ×_{Proj 𝒜} U_j → U_i × U_j` are closed immersions.
  - Identify these pullbacks with `Spec` of tensor products of away-localizations.
  - Construct a surjective ring map between these tensor products and apply `IsClosedImmersion.spec_of_surjective`.

- **Key Steps**:
  1. Use `IsLocalAtTarget.of_openCover` to reduce to checking on affine opens.
  2. Use isomorphisms:
     - `pullbackAwayιIso` to identify pullback of affines with `Spec` of `Away 𝒜 (i.2 * j.2)`.
     - `pullbackSpecIso` to identify tensor product of away-localizations with `Spec` of tensor product.
  3. Define ring map `F` via `Algebra.TensorProduct.lift`.
  4. Prove `F` is surjective using `lift_awayMapₐ_awayMapₐ_surjective`.
  5. Apply `IsClosedImmersion.spec_of_surjective`.
  6. Conclude via cancellation lemmas (`cancel_left_of_respectsIso`, `cancel_right_of_respectsIso`).

- **Inductive/Case Analysis**:
  - `cases d` eliminates `d = 0` using `hd : 0 < d`.
  - `by_cases hfg : (f * g)^j = 0` handles nilpotent cases via `Subsingleton`.
