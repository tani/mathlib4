- **Structure of proofs**:
  - **Induction / case analysis** on subtype elements (`⟨U, hU⟩`).

  - **Ideal-theoretic characterizations** (e.g., `Ideal.span s = ⊤ ↔ ⋃ D(f) = U`).
  - **Sieve generation lemmas** often reduce to algebraic identities like `D(f) ∩ D(g) = D(fg)`.

- **Common proof patterns**:
  - Proving sieve membership by constructing a factorization through basic opens.
  - Using `X.basicOpen_basicOpen_is_basicOpen` to reduce intersections of basic opens to single basic opens.
  - Leveraging `mem_grothendieckTopology` to translate topology membership into pointwise openness conditions.

- **Key logical flow**:
  1. Unfold definitions (`grothendieckTopology`, `presieveOfSections`, etc.).

  3. Use algebraic geometry facts (e.g., basis of opens is `D(f)`).

  5. Conclude via equivalence or universal property.

### Summary

This file formalizes the **small affine Zariski site** of a scheme `X`, where:
- Objects = affine open subsets of `X`.
- Morphisms = basic opens `D(f) → U`, i.e., inclusions induced by global sections.
- Covers = sets of sections generating the unit ideal.

It establishes:
- A **dense subsite** embedding into the big Zariski site.
- A **bijection** between presieves and sets of sections.
- A **characterization** of covering sieves via ideal-theoretic conditions.
- An **equivalence of sheaf categories**, enabling descent arguments.

This is foundational for descent theory and cohomological constructions in algebraic geometry.
