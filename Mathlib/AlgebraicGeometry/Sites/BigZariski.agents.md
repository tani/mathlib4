#### **3. Tactic Stack**

The proof of `subcanonical_zariskiTopology` uses the following tactics in sequence:

- `intro X`: Introduce an object.
- `rw [Presieve.isSheaf_pretopology]`: Rewrites the sheaf condition for a pretopology.
- `rintro Y S ⟨𝓤,rfl⟩ x hx`: Introduces and destructures a sieve and a compatible family.
- `let e := ...`: Constructs a morphism using `glueMorphisms`.
- `refine ⟨e, ?_, ?_⟩`: Splits the goal into two subgoals (commutativity and uniqueness).
- `dsimp [e]`: Simplifies using the definition of `e`.
- `rw [𝓤.ι_glueMorphisms]`: Rewrites using the universal property (ι-maps of the sieve).
- `apply 𝓤.hom_ext`: Uses extensionality for morphisms in the sieve category.
- `intro j`: Intro a morphism in the sieve.
- `exact h (...)`: Applies compatibility condition `hx`.

**Key tactics**: `intro`, `rw`, `refine`, `dsimp`, `apply`, `exact`, `hom_ext`.

#### **4. Proof Logic**

- **Goal**: Show that representable presheaves `yoneda X` are sheaves for `zariskiTopology`.
- **Strategy**:
  1. Reduce to checking the sheaf condition for the *pretopology* (via `of_isSheaf_yoneda_obj`).
  2. Unfold the sheaf condition for a pretopology: for any covering sieve `S` generated by open immersions `𝒰 : J → Over X`, a compatible family `x : ∀ j, Y ⟶ U_j` glues uniquely to `e : Y ⟶ X`.
  3. Construct `e` using `glueMorphisms`, which exists because `𝒰` is a pullback-stable sieve (open immersions are stable under pullback).
  4. Verify:
     - **Commutativity**: Each component `e ∘ ι_j = x_j` via `ι_glueMorphisms`.
     - **Uniqueness**: If `e'` also satisfies this, then `e = e'` by `hom_ext`, using compatibility `hx`.

- **Core idea**: The Zariski topology is defined so that open immersions form a pretopology, and schemes satisfy descent for such covers — i.e., they are *sheaves for open immersions*, which is exactly what `subcanonical` asserts.
