### Technical Brief: Equivalent Power-Multiplicative Norms in Lean 4

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `IsPowMul` | `β → ℝ → Prop` (implicit) | Predicate stating that a function `nβ : β → ℝ` is *power-multiplicative*: `nβ (x ^ n) = nβ x ^ n` for all `n : ℕ`. Used to model norms that behave multiplicatively on powers (e.g., non-Archimedean norms). |
| `contraction_of_isPowMul_of_boundedWrt` | `{f : α →+* β} → f.IsBoundedWrt nα nβ → ∀ x, nβ (f x) ≤ nα x` | Shows that if a ring homomorphism `f` is bounded w.r.t. a ring seminorm `nα` and a power-multiplicative function `nβ`, then `f` is a *contraction*: `nβ ∘ f ≤ nα`. |
| `contraction_of_isPowMul` | `[SeminormedRing α] [SeminormedRing β] → IsPowMul norm → f.IsBounded → ∀ x, ‖f x‖ ≤ ‖x‖` | Special case of above for the canonical norm on seminormed rings. |
| `eq_seminorms` | `{f g : F} → IsPowMul f → IsPowMul g → (∃ r > 0, f ≤ r • g) → (∃ s > 0, g ≤ s • f) → f = g` | Proves equality of two power-multiplicative ring seminorms under mutual boundedness (i.e., equivalence up to positive constants). |
| `eq_of_powMul_faithful` | `(f₁ f₂ : AlgebraNorm R S) → IsPowMul f₁ → IsPowMul f₂ → (∀ y, f₁ ≃ᶠ[𝓝] f₂ on `Algebra.adjoin R {y}`) → f₁ = f₂` | Main theorem: if two power-multiplicative algebra norms agree *locally* on each singly-generated subalgebra `R[y]`, then they are globally equal. This formalizes [BGR, Prop. 3.1.5/1]. |

#### **2. Naming Conventions**

- **`is_` prefix**: Used for properties (`IsPowMul`, `IsBounded`, `IsBoundedWrt`) — standard in Mathlib for predicate classes.
- **`contraction_of_` prefix**: Indicates a result showing that a bounded map is a contraction under additional assumptions (e.g., power-multiplicativity).
- **`eq_` prefix**: Used for uniqueness/equality results (`eq_seminorms`, `eq_of_powMul_faithful`).
- **`restriction`**: Refers to restricting an algebra norm to a subalgebra (used in `eq_of_powMul_faithful` proof).
- **`map_pow_le_pow` / `RingHom.map_pow`**: Standard homomorphism properties of powers.
- **`rpow_*`**: Real power (`x ^ (1/n)`) lemmas used in limit arguments.

---

#### **3. Tactic Stack**

The proofs rely heavily on:

- `obtain` / `rcases`: To unpack existential hypotheses.
- `rw [← ...]`: Rewriting using ring homomorphism and power properties.
- `simp only [eventually_atTop, ge_iff_le]`: Simplification for filter/tendsto goals.
- `apply le_of_pow_le_pow_left₀`: Key for comparing powers in inequalities (non-Archimedean style).
- `rpow_*` lemmas: `rpow_mul`, `rpow_natCast`, `inv_mul_cancel₀`, etc., for manipulating real powers.
- `tendsto_*` tactics: `tendsto_const_div_atTop_nhds_zero_nat`, `ContinuousAt.tendsto`, etc., for asymptotic analysis.
- `le_antisymm`: Final step in `eq_seminorms` and `eq_of_powMul_faithful` to conclude equality.
- `ext`: Extensionality for function equality (used in `eq_seminorms` and `eq_of_powMul_faithful`).
- `aesop` is *not* used — proofs are highly manual and rely on precise algebraic/analytic reasoning.

---

#### **4. Proof Logic**

- **Structure of `eq_of_powMul_faithful`:**
  1. Reduce global equality to pointwise equality (`ext x`).
  2. Localize to the subalgebra `A = Algebra.adjoin R ({x} : Set S)` generated by `x`.
  3. Restrict `f₁`, `f₂` to `A`, obtaining `g₁`, `g₂`, which remain power-multiplicative (`IsPowMul.restriction`).
  4. Use the hypothesis `h_eq` to get constants `C₁, C₂ > 0` bounding `g₁` and `g₂` on `A`.
  5. Apply `eq_seminorms` to conclude `g₁ = g₂`, hence `f₁ x = f₂ x`.

- **Core logical flow in supporting lemmas:**
  - **Bounded ⇒ contraction**: Use definition of boundedness (`∃ C, ...`), then analyze asymptotics of `C^(1/n)` → 1, and use power-multiplicativity to relate `nβ(f(x)^n)` and `nα(x)^n`.
  - **Mutual boundedness ⇒ equality**: Apply contraction result twice (in both directions) and use `le_antisymm`.

- **Induction is not used** — the argument is analytic (via limits) and algebraic (via power properties).

---

#### **5. Imports & Scope**

- **Core dependencies**:
  - `Mathlib.Analysis.Normed.Algebra.Norm`: Provides `AlgebraNorm`, `norm`, and basic normed algebra structure.
  - `Mathlib.Analysis.SpecialFunctions.Pow.Continuity`: Supplies continuity and limit properties of real powers (`rpow`), crucial for the `tendsto` arguments.

- **Domain scope**:
  - Non-Archimedean functional analysis / rigid analytic geometry (per BGR reference).
  - Focus on *algebra norms* on algebras over normed commutative rings.
  - Assumes `R` is a `NormedCommRing`, `S` a `CommRing` with `Algebra R S`.

- **Notable abstractions**:
  - `AlgebraNorm R S`: Type of norms on `S` compatible with the `R`-algebra structure.
  - `Algebra.adjoin R ({y} : Set S)`: The smallest sub-`R`-algebra containing `y`.
  - `RingSeminormClass`, `FunLike`: Typeclass machinery for seminorms as functions.

---

### Summary

This file formalizes a foundational uniqueness result for power-multiplicative algebra norms: local equivalence on finitely generated subalgebras implies global equality. It leverages deep interplay between algebraic structure (ring homomorphisms, powers), analytic tools (limits, continuity of real powers), and Lean’s typeclass system (e.g., `IsPowMul`, `IsBoundedWrt`). The proofs are constructive and highly manual, avoiding automation in favor of precise control over inequalities and limits.
