### 🔹 **Proof Logic / Strategy**

- **Induction-free**: No structural induction; relies on categorical universal properties.
- **Core pattern**:
  1. Use `IsGenerating.le` to extract a 1-hypercover `E` refining a given covering sieve `S`.
  2. Assume all such `E` yield limit multiforks (`hP`).
  3. Construct the mediating morphism via `Multifork.IsLimit.lift`.
  4. Prove uniqueness via `hom_ext`, using the fact that `E.sieve₀ ≤ S`.
  5. Prove factorization via `fac`, using pullback stability of coverings.
- **Sheaf ⇔ limit over 1-hypercovers**: The equivalence is proven by:
  - `(→)`: Sheaf ⇒ limit over *all* covering sieves ⇒ limit over those induced by `E`.
  - `(←)`: Assume limit over `H`-selected `E`, then show limit over *any* covering sieve using refinement.
