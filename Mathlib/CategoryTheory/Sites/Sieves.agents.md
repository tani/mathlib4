### 🔑 **Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `Presieve X` | `∀ {Y}, Set (Y ⟶ X)` | A *presieve* on `X` is a set of arrows into `X`, not necessarily closed under precomposition. |
| `Sieve X` | `Structure { arrows : Presieve X; downward_closed : ... }` | A *sieve* on `X` is a presieve closed under left-composition (i.e., precomposition with any arrow). |
| `generate R` | `Presieve X → Sieve X` | Generates the smallest sieve containing a given presieve `R`. |
| `pullback f S` | `f : Y ⟶ X → Sieve X → Sieve Y` | Pullback of a sieve `S` along `f`: `g ∈ pullback f S ⇔ g ≫ f ∈ S`. |
| `pushforward f R` | `f : Y ⟶ X → Sieve Y → Sieve X` | Pushforward of a sieve `R` along `f`: `g ∈ pushforward f R ⇔ ∃ h ∈ R, h ≫ f = g`. |
| `functorPullback F R` | `F : C ⥤ D → Sieve (F.obj X) → Sieve X` | Preimage of a sieve under a functor: `f ∈ F⁻¹(S) ⇔ F.map f ∈ S`. |
| `functorPushforward F R` | `F : C ⥤ D → Sieve X → Sieve (F.obj X)` | Sieve generated by image of `R` under `F`. |
| `bind S R` | `Presieve X → (∀ f : S, Sieve _) → Sieve X` | Bind operation: for each `f ∈ S`, attach a sieve on `dom(f)`, then compose. |
| `ofArrows Y f` | `(Y : I → C) → (∀ i, Y i ⟶ X) → Sieve X` | Sieve generated by a family of arrows `f i : Y i ⟶ X`. |
| `ofObjects Y X` | `(Y : I → C) → C → Sieve X` | Sieve of arrows factoring through some `Y i`. |
| `giGenerate` | `GaloisInsertion generate arrows` | `generate` ⊣ `arrows` as a Galois insertion. |
| `galoisConnection f` | `GaloisConnection (pushforward f) (pullback f)` | `pushforward f ⊣ pullback f`. |
| `pullbackArrows_comm` | `Sieve.generate (R.pullbackArrows f) = (Sieve.generate R).pullback f` | Compatibility of pullback arrows construction with sieve generation. |
| `id_mem_iff_eq_top` | `S (𝟙 X) ↔ S = ⊤` | A sieve is maximal iff it contains the identity. |
| `generate_of_contains_isSplitEpi` | `IsSplitEpi f → R f → generate R = ⊤` | If a presieve contains a split epi, its generated sieve is top. |

- **Suffixes**:

### 🧠 **Proof Logic & Strategy**

- **Induction & Cases**: Used for inductive definitions (`singleton'`, `ofArrows`, `pullbackArrows`).
- **Extensionality**: `Sieve.ext`, `Presieve.ext`, `funext` dominate equality proofs.
- **Galois Connections**: Central proof technique — many results are derived from `galoisConnection`, `functor_galoisConnection`, `giGenerate`.
- **Factorization Arguments**: Proving membership in `generate R`, `bind`, `pushforward` often involves constructing factorizations.
- **Downward Closure**: Used repeatedly to propagate membership through precomposition.
- **Choice & Noncomputability**: `Nonempty.some`, `choose`, `noncomputable def` used for definitional choices (e.g., `bindStruct`, `ofArrows.i`, `ofArrows.h`).
- **Monomorphism / Split Epi Reasoning**: Specialized lemmas (`cancel_mono`, `section_`, `isSplitEpi`) simplify arguments about maximality and adjunctions.
