### **1. Key Definitions & Theorems**

| Name | Type / Structure | Purpose |
|------|------------------|---------|
| `PreOneHypercover S` | `structure` | Categorical data for a 1-hypercover over `S`: a family `X i ⟶ S` indexed by `I₀`, and for each pair `(i₁, i₂)`, a family `Y j` with maps to the (formal) pullback of `X i₁`, `X i₂` over `S`. |
| `sieve₁ p₁ p₂` | `Sieve W` | Sieve on `W` generated by morphisms factoring through some `Y j` via `p₁`, `p₂`. Encodes the “covering condition” on the pullback square. |
| `sieve₁' i₁ i₂` | `Sieve (pullback (f i₁) (f i₂))` | Sieve on the actual pullback (when it exists), generated by maps `Y j ⟶ pullback`. |
| `multicospanShape` | `MulticospanShape` | Shape for the multifork diagram associated to a `PreOneHypercover`: left objects = `I₀`, right objects = `I₁' = Σ_{i₁,i₂} I₁ i₁ i₂`. |
| `multicospanIndex F` | `MulticospanIndex` | Diagram in `[Cᵒᵖ, A]` induced by a presheaf `F`, using `F.map (p₁ j).op`, `F.map (p₂ j).op`. |
| `multifork F` | `Multifork` | Canonical multifork from `F.obj (op S)` to the multicospan diagram. |
| `isLimitMultiforkEquivIsLimitFork` | `IsLimit (multifork F) ≃ IsLimit (forkOfIsColimit hc hd F)` | Equivalence between limiting multifork and limiting fork obtained by collapsing coproducts. |
| `sigmaOfIsColimit hc hd` | `PreOneHypercover S` | Simplified 1-hypercover with single `Y`-component (the colimit of `Y'`) and single `I₁`-index (`PUnit`). |
| `isLimitSigmaOfIsColimitEquiv` | `IsLimit (multifork (sigmaOfIsColimit hc hd F)) ≃ IsLimit (multifork F)` | Reduction of limiting multifork condition to the simpler `sigmaOfIsColimit` case. |
| `trivial S` | `PreOneHypercover S` | Trivial 1-hypercover: single component `S`, `I₁ = PUnit`, `Y = S`, projections = identities. |
| `OneHypercover S` | `structure` | `PreOneHypercover S` + topological conditions: `sieve₀ ∈ J S`, and `sieve₁ p₁ p₂ ∈ J W` for all compatible `p₁, p₂`. |
| `OneHypercover.mk'` | `def` | Construction criterion: if `sieve₀ ∈ J S` and `sieve₁' i₁ i₂ ∈ J _`, then it's a `1`-hypercover. |
| `OneHypercover.isLimitMultifork` | `def` | **Main theorem**: For `E : J.OneHypercover S` and `F : Sheaf J A`, the multifork `E.multifork F` is limiting — i.e., `F.obj (op S)` is the multiequalizer of the pair of maps induced by `p₁, p₂`. |
| `OneHypercover.amalgamate` | `def` | Gluing of compatible sections over a `1`-hypercover (used in sheaf axioms). |
| `Cover.oneHypercover` | `def` | Canonical 1-hypercover associated to a covering sieve `S : J.Cover X`, using pullback cones as `I₁`. |
| `PreZeroHypercover.toPreOneHypercover` | `def` | Canonical 1-hypercover structure on a 0-hypercover when pullbacks exist: `I₁ = PUnit`, `Y = pullback`. |

### **2. Naming Conventions**

- **Prefixes**:
  - `PreOneHypercover.*`: Base categorical data (no topology).
  - `OneHypercover.*`: Topological version (sieves in `J`).
  - `sieve₀`, `sieve₁`: Sieves associated to 0- and 1- level.
  - `multifork`, `multicospan*`: Multifork/multicospan constructions.
  - `σOfIsColimit`, `sigmaOfIsColimit`: “Sigma” simplification via colimits.
  - `trivial`: Canonical minimal example.

- **Suffixes**:
  - `'` (e.g., `mem₁'`, `sieve₁'`): Variant or “prime” version (often on pullback object).
  - `Lift`, `Fst`, `Snd`: Projection or universal morphisms.
  - `E`, `F`, `G`: Generic hypercovers; `c`, `d`: Colimits used in constructions.

- **Variables**:
  - `i, j, k`: Indices in `I₀`, `I₁`.
  - `p₁, p₂`: Projections to components.
  - `w`: Compatibility condition `p₁ ≫ f i₁ = p₂ ≫ f i₂`.

### **4. Proof Logic**

**Typical proof pattern**:

1. **Structural decomposition**:
   - Work with `PreOneHypercover` first (categorical data).
   - Add topology via `OneHypercover.mem₀`, `mem₁`.

2. **Equational reasoning**:
   - Use `sieve₁_eq_pullback_sieve₁'`, `sieve₁'_eq_sieve₁` to relate sieve definitions.
   - Prove sieves are covering using `J.pullback_stable`, `J.bind_covering`.

3. **Limit preservation**:
   - Reduce `IsLimit (multifork F)` to `IsLimit (forkOfIsColimit hc hd F)` via `isLimitMultiforkEquivIsLimitFork`.
   - Use `Multifork.isLimitEquivOfIsos`, `IsLimit.ofConeEquiv`, `Fan.IsLimit.hom_ext`.

4. **Sheaf gluing**:
   - For `OneHypercover.amalgamate`, verify compatibility → use `Presieve.IsSheafFor.valid_glue`.
   - Use `arrowsCompatible` + `isSeparated` to ensure uniqueness.

5. **Universal properties**:
   - Construct morphisms of hypercovers via `Hom`, `interLift`.
   - Prove uniqueness using `Hom.ext`.
