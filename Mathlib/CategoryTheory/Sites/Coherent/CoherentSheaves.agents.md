### Technical Metadata Brief

#### 1. **Key Definitions & Theorems**

| Name | Type / Purpose |
|------|----------------|
| `coherentTopology` | A Grothendieck topology on a precoherent category `C`, defined via finite effective epimorphic families (see `Presieve.isSheaf_coverage`). |
| `isSheaf_coherent` | **Main theorem**: A presheaf `P : Cᵒᵖ ⥤ Type w` is a sheaf for the coherent topology iff it satisfies the sheaf condition for *every* finite effective epimorphic presieve. |
| `isSheaf_yoneda_obj` | Every Yoneda presheaf `yoneda.obj W` is a sheaf for the coherent topology — i.e., the coherent topology is *subcanonical*. |
| `subcanonical` | Instance showing that the coherent topology is subcanonical, derived from `isSheaf_yoneda_obj`. |
| `Presieve.IsSheaf` | Standard sheaf condition for a presieve (i.e., descent data is effective). |
| `EffectiveEpiFamily` | A family of arrows `π : (a : α) → X a ⟶ B` is an *effective epimorphic family* if the induced map `∐ X a → B` is an effective epimorphism (in the categorical sense). |
| `Sieve.generate` / `Presieve.ofArrows` | Construction of a sieve from a family of arrows; used to relate presieves to sieves in the topology. |
| `yoneda.obj` | The Yoneda embedding applied to an object `W : C`, yielding a presheaf `C(-, W)`. |

#### 2. **Naming Conventions**

- **Prefixes**:
  - `isSheaf_`: Predicate that a presheaf satisfies the sheaf condition for a given topology/presieve.
  - `coherentTopology_`: Functions/instances related to the coherent topology.
  - `yoneda_`: Related to the Yoneda embedding.
- **Suffixes**:
  - `_obj`: Applied to functors (e.g., `yoneda.obj W`).
  - `_family`: Refers to families of morphisms (e.g., `EffectiveEpiFamily X π`).
- **Descriptive patterns**:
  - `ofArrows`: Constructs a presieve from a family of arrows.
  - `generate`: Builds a sieve from a presieve or family.
  - `extend` / `amalgamation`: Refers to gluing/extension of compatible families.

#### 3. **Tactic Stack**

- `rw`: Rewriting using equivalences/definitions (e.g., `coherentTopology`, `Sieve.generateFamily_eq`, `yoneda` lemmas).
- `simp only [...]`: Simplification with a precise set of lemmas (e.g., `coherentTopology`, `Presieve.isSheaf_coverage`).
- `intro` / `intro h`: Standard intro-style reasoning.
- `apply`: Used to apply a hypothesis or lemma (e.g., `apply hP`).
- `convert`: Used for congruence-based equality proofs (e.g., `convert ... using ...`).
- `obtain ⟨t, t_amalg, t_uniq⟩`: Destructuring existential-uniqueness statements.
- `refine ⟨t, ?_, ?_⟩`: Constructing a pair with holes to be filled.
- `exact`: Finalizing trivial or already-known goals.

No heavy automation (e.g., `aesop`, `ring`, `linarith`) is used — the proofs are largely *manual category-theoretic reasoning*.

#### 4. **Proof Logic**

- **Forward direction (`→`)** of `isSheaf_coherent`:
  - Assume `P` is a sheaf for `coherentTopology`.
  - Use the definition of `coherentTopology` as a *coverage* (`Presieve.isSheaf_coverage`).
  - Instantiate the coverage condition with a finite effective epimorphic family (via `⟨α, inferInstance, X, π, rfl, h⟩`).
- **Reverse direction (`←`)**:
  - Assume `P` satisfies sheaf condition for all finite effective epimorphic presieves.
  - Use the definition of `coherentTopology` again: any covering sieve is generated by such a finite effective epimorphic family.
  - Apply the hypothesis directly.
- **Yoneda sheaf proof (`isSheaf_yoneda_obj`)**:
  - Reduce to checking sheaf condition for finite effective epimorphic presieves (via `isSheaf_coherent`).
  - Use the fact that effective epimorphic families induce colimits (via `isColimitOfEffectiveEpiFamilyStruct`).
  - Translate the sheaf condition into colimit descent using `Sieve.forallYonedaIsSheaf_iff_colimit`.
  - Construct the unique amalgamation using Yoneda + colimit universal property.
  - Verify compatibility and uniqueness via `sieveExtend`, `restrict`, and uniqueness in colimit.
