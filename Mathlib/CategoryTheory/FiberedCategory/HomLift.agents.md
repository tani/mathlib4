#### **2. Naming Conventions**

- **Prefixes**:
  - `isHomLift` / `IsHomLift`: class and namespace.
  - `lift_`: e.g., `lift_id`, `lift_eqToHom_*`, `comp_lift_id_*`.
  - `eqToHom_*_lift_*`: e.g., `eqToHom_domain_lift_id`, `lift_eqToHom_comp`.
  - `fac`, `fac'`: factorization lemmas.
  - `commSq`: commutative square lemmas.

- **Suffixes**:
  - `_iff`: logical equivalence lemmas.
  - `_left`, `_right`: indicate position in composition (e.g., left/right identity lifting).
  - `'` (prime): variant of a lemma (often dual or symmetric).
  - `inv`: for inverses (e.g., `inv_lift`, `inv_lift_inv`).

- **Macro**:
  - `subst_hom_lift`: tactic macro for substitution using lifting evidence.

#### **4. Proof Logic**

- **Core Strategy**:
  - Use `subst_hom_lift` to reduce goals to cases where `f = p.map φ` definitionally.
  - Then apply `simp` with lemmas like `fac`, `fac'`, `map_id`, `map_comp`, and `eqToHom_*`.
  - For composition/identity/iso properties, construct witnesses via `of_fac`, `of_commsq`, `of_commSq`, or use `inferInstance` after simplifying.

- **Inductive Structure**:
  - `IsHomLiftAux` is inductively generated by `map`, so all proofs about `IsHomLift` ultimately reduce to reasoning about `p.map φ`.

- **Common Patterns**:
  - **Domain/codomain alignment**: Use `domain_eq`, `codomain_eq` to get `p.obj a = R`, `p.obj b = S`.
  - **Equality of morphisms**: Reduce to `f = p.map φ` via `eq_of_isHomLift`, or construct via `of_fac`/`of_commSq`.
  - **Isomorphisms**: Use `isoOfIsoLift` to lift isos, and `isIso_of_lift_isIso` / `inv_lift` for closure under inverses.
  - **Stability under `eqToHom`**: Use `eqToHom_*_lift_*` instances and their `*_iff` variants.
