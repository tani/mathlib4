### Technical Metadata Brief: `DFinsupp.Extensionality` (Lean 4)

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `add_closure_iUnion_range_single` | `AddSubmonoid.closure (⋃ i, Set.range (single i)) = ⊤` | Shows that the additive submonoid generated by all `single i y` elements is the entire `Π₀ i, β i`. This is the *density* condition used for extensionality. |
| `addHom_ext` | `∀ {f g : (Π₀ i, β i) →+ γ}, (∀ i y, f (single i y) = g (single i y)) → f = g` | Extensionality principle: two additive homomorphisms out of `Π₀ i, β i` are equal if they agree on all `single` elements. |
| `addHom_ext'` | `∀ {f g : (Π₀ i, β i) →+ γ}, (∀ x, f ∘ singleAddHom β x = g ∘ singleAddHom β x) → f = g` | Equivalent formulation using composition with `singleAddHom`; supports the `@[ext]` attribute for use with `ext` tactic. |
| `single` | `β i → Π₀ j, β j` | Canonical embedding of a single component into the dependent finite support function space. |
| `singleAddHom` | `β i →+ Π₀ j, β j` | Additive homomorphism version of `single`. |

---

#### **2. Naming Conventions**

- **Prefixes**:
  - `add_`: indicates additive structure (e.g., `addHom_ext`, `add_closure`).
  - `single_`: pertains to the `single` function (e.g., `singleAddHom`, `range_single`).
- **Suffixes**:
  - `_ext`: extensionality lemmas (e.g., `addHom_ext`, `addHom_ext'`).
  - `_mem`, `_subset`, `_closure`: used in submonoid/set inclusion arguments.
- **Functional style**:
  - `comp` used for composition (`f.comp g` ≡ `f ∘ g` in `AddMonoidHom`).
  - `DFunLike.congr_fun` used to extract pointwise equality from function extensionality.

- **Core tactics**:
  - `refine`, `apply`, `intro`, `cases`, `rcases`, `exact`

- **Extensionality**:
  - `AddMonoidHom.eq_of_eqOn_denseM` (key lemma for extensionality via dense generators)

---

#### **4. Proof Logic**

- **Structure of `addHom_ext`**:
  1. Use `AddMonoidHom.eq_of_eqOn_denseM` with the dense set given by `add_closure_iUnion_range_single`.
  2. Reduce goal to showing `f = g` on the dense set: `⋃ i, range (single i)`.
  3. Unpack membership in the union/range: `∃ i y, x = single i y`.
  4. Apply hypothesis `H i y`.

- **Structure of `addHom_ext'`**:
  1. Reduce to `addHom_ext` using `DFunLike.congr_fun` to convert pointwise equality of compositions into equality on `single` values.

- **Inductive reasoning** (in `add_closure_iUnion_range_single`):
  - Uses `DFinsupp.induction` (induction on finite support functions) to show closure under addition and zero.

---

#### **5. Imports & Scope**

- **Core dependencies**:
  - `Mathlib.Algebra.Group.Submonoid.Basic`: for `AddSubmonoid`, `closure`, `top_unique`, etc.
  - `Mathlib.Data.DFinsupp.Defs`: defines `Π₀ i, β i`, `single`, `singleAddHom`, and basic properties.

- **Domain**:
  - Dependent finite support functions (`Π₀`), additive monoids/homomorphisms.
  - Requires `DecidableEq ι` and `AddZeroClass (β i)` for all `i`.

- **Use case**:
  - Enables proving equality of additive homomorphisms from `Π₀ i, β i` by checking agreement on generators (`single`), crucial for universal properties and constructions involving `DFinsupp`.
