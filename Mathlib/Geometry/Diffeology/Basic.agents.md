### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `DiffeologicalSpace X` | `Type u → Type u` (class) | Defines a diffeology on a type `X`: a family of plots `plots n : Set (𝔼ⁿ → X)` satisfying three axioms (constants, reparametrisation, locality), plus a D-topology. |
| `plots n` | `Set (𝔼ⁿ → X)` | The set of *plots* (smooth maps) from `𝔼ⁿ` into `X`. |
| `IsPlot p` | `p ∈ plots n` | Predicate stating that `p : 𝔼ⁿ → X` is a plot. |
| `DSmooth f` | `∀ n p, IsPlot p → IsPlot (f ∘ p)` | Predicate stating that `f : X → Y` is smooth (i.e., preserves plots). |
| `dTopology` | `TopologicalSpace X` | The *D-topology*: finest topology making all plots continuous. Defined as `IsOpen u ↔ ∀ p ∈ plots n, IsOpen (p ⁻¹' u)`. |
| `IsDTopologyCompatible X` | `dTopology = t` | Typeclass stating that a given topology `t` on `X` coincides (defeq or not) with the D-topology. |
| `NormedSpace.toDiffeology` | `FiniteDimensional ℝ X ⇒ DiffeologicalSpace X` | Standard diffeology on finite-dimensional normed spaces: plots are globally smooth maps `𝔼ⁿ → X`. |
| `IsContDiffCompatible X` | `IsPlot p ↔ ContDiff ℝ ∞ p` | Typeclass stating that the diffeology coincides with the one induced by `ContDiff ℝ ∞`. |
| `isPlot_iff_dSmooth` | `IsPlot p ↔ DSmooth p` | A map `𝔼ⁿ → X` is a plot iff it is smooth (as a map into `X`). |
| `dSmooth_iff_contDiff` | `DSmooth f ↔ ContDiff ℝ ∞ f` | For finite-dimensional normed spaces, smoothness in the diffeological sense coincides with classical smoothness. |

### **2. Naming Conventions**

- **Predicates**: `isPlot`, `DSmooth`, `isPlotOn`, `isPlot_const`, `isPlot_reparam`, `isPlot_iff_*`, `isContDiffCompatible`, `isOpen_iff_*`
- **Constructors / Helpers**: `ofCorePlotsOn`, `replaceDTopology`, `ofPlotsOn` (mentioned in docstring)
- **Topological terms**: `dTopology`, `IsDTopologyCompatible`, `IsContDiffCompatible`
- **Aliases**: `𝔼ⁿ` for `EuclideanSpace ℝ (Fin n)`, `dTopology` aliased as `Diffeology.dTopology`
- **Suffixes**:
  - `_comp`, `_comp'`: for composition variants (`dSmooth_comp`, `dSmooth_comp'`)
  - `_iff_*`: for equivalences (`isPlot_iff_dSmooth`, `dSmooth_iff_contDiff`)
  - `_compatible`: for typeclasses encoding definitional coherence (`IsDTopologyCompatible`, `IsContDiffCompatible`)
