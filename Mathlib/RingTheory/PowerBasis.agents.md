### Technical Brief: `PowerBasis` in Lean 4 (Mathlib)

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `PowerBasis R S` | `Structure` | Represents a finite power basis `1, x, ..., x^(n-1)` for an `R`-algebra `S`. Contains `gen : S`, `dim : ℕ`, `basis : Basis (Fin dim) R S`, and `basis_eq_pow : ∀ i, basis i = gen^i`. |
| `minpolyGen pb` | `A[X]` | Explicit minimal polynomial of `pb.gen`, defined as `X^dim - ∑_{i<dim} c_i X^i`, where `c_i` are coordinates of `pb.gen^dim` in the basis. |
| `aeval_minpolyGen pb` | `aeval pb.gen (minpolyGen pb) = 0` | Shows `pb.gen` is a root of its minimal polynomial. |
| `minpolyGen_monic pb` | `Monic (minpolyGen pb)` | Proves `minpolyGen pb` is monic. |
| `dim_le_natDegree_of_root pb` | `p ≠ 0 → aeval pb.gen p = 0 → pb.dim ≤ p.natDegree` | Minimal polynomial has minimal degree among nonzero polynomials annihilating `pb.gen`. |
| `lift pb y hy` | `S →ₐ[A] S'` | Algebra homomorphism induced by sending `pb.gen` to `y`, provided `y` is a root of `minpoly A pb.gen`. |
| `liftEquiv pb` | `(S →ₐ[A] S') ≃ { y // aeval y (minpoly A pb.gen) = 0 }` | Bundled equivalence between algebra maps and roots of the minimal polynomial. |
| `equivOfRoot pb pb' h₁ h₂` | `S ≃ₐ[A] S'` | Algebra isomorphism when each generator is a root of the other’s minimal polynomial. |
| `linearIndependent_pow x` | `LinearIndependent K fun i : Fin (minpoly K x).natDegree => x^i` | Powers of `x` up to `natDegree(minpoly x) - 1` are linearly independent. |
| `adjoin_gen_eq_top B` | `adjoin R ({B.gen}) = ⊤` | The subalgebra generated by `B.gen` is the whole algebra `S`. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `minpolyGen_`: properties of the *explicit* minimal polynomial (e.g., `minpolyGen_monic`, `aeval_minpolyGen`).
  - `lift_`: algebra maps induced by power basis (e.g., `lift_gen`, `lift_aeval`).
  - `equivOf_`: equivalences/isomorphisms between algebras with matching minimal polynomials (e.g., `equivOfRoot`, `equivOfMinpoly`).
  - `constr_pow_`: universal property of basis construction (e.g., `constr_pow_aeval`, `constr_pow_gen`).
- **Suffixes**:
  - `_eq`: equality of expressions (e.g., `minpolyGen_eq`, `equivOfRoot_gen`).
  - `_map`: behavior under algebra isomorphism (e.g., `minpolyGen_map`).
  - `_top`: maximality (e.g., `adjoin_gen_eq_top`).
- **General**:
  - `mem_span_pow`, `mem_span_pow'`: membership in span of powers.
  - `dim_*`: dimension-related facts (`dim_ne_zero`, `dim_pos`, `finrank`).
  - `exists_*`: existence of representations (e.g., `exists_eq_aeval`, `exists_smodEq`, `exists_gen_dvd_sub`).

#### **3. Tactic Stack**

Frequently used tactics in proofs:
- `simp` / `simp_rw`: Simplification with many lemmas (especially `basis_eq_pow`, `aeval_C`, `aeval_X`, `minpoly.aeval`).
- `rw`: Rewriting using equalities like `minpolyGen_eq`, `aeval_minpolyGen`, `lift_gen`.
- `convert`: To match goals up to definitional equality (e.g., in `lift_aeval`, `constr_pow_mul`).
- `exact`, `refine`, `apply`: For direct proof construction.
- `cases subsingleton_or_nontrivial _`: Split into trivial and nontrivial cases (common in algebraic contexts).
- `aesop`: Used sparingly, mostly for routine simplification.
- `ring`: For polynomial arithmetic (e.g., in `minpolyGen_monic`, `degree_minpolyGen`).
- `apply_fun`, `convert`, `nth_rewrite`: For manipulating equations involving coefficients or degrees.
- `ext`: Extensionality for functions/homomorphisms (e.g., `algHom_ext`, `lift_aeval`).
- `rw [← ...]`: Reverse rewriting to apply known identities (e.g., `aeval_modByMonic_eq_self_of_root`).

---

#### **4. Proof Logic**

Typical proof patterns:
- **Induction / finite case analysis**: Often on `dim` or `natDegree`.
- **Basis expansion**: Use `pb.basis.sum_repr` or `pb.basis.linearCombination_repr` to express elements in terms of powers of `gen`.
- **Polynomial division**: Reduce modulo `minpoly` (e.g., `modByMonic_add_div`, `aeval_modByMonic_eq_self_of_root`) to bound degree.
- **Universal property of basis construction**: Use `pb.basis.constr` to define algebra maps and verify algebra homomorphism properties.
- **Equivalence via mutual roots**: Prove `S ≃ₐ S'` by constructing maps in both directions using `lift`, then show they’re inverses.
- **Degree comparison**: Use `dim_le_degree_of_root` to compare degrees of polynomials annihilating `gen`.
- **Subsingleton handling**: Many proofs split on `subsingleton_or_nontrivial` to handle degenerate cases (e.g., zero ring).

### Summary

This file formalizes the theory of *power bases* — finite bases of the form `1, x, ..., x^(n-1)` — for algebras over commutative rings/fields. It provides:
- A structural definition (`PowerBasis`),
- A canonical minimal polynomial (`minpolyGen`),
- A universal property for algebra maps (`lift`),
- Equivalences between algebras with matching minimal polynomials (`equivOfRoot`, `equivOfMinpoly`),
- Applications to algebraic extensions (e.g., `adjoin_gen_eq_top`, `finite`, `finrank`).

It is foundational for algebraic number theory and field extensions in Mathlib.
