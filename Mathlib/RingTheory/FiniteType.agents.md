### Technical Metadata Brief: `Mathlib.Algebra.FiniteType`

---

#### **1. Key Definitions & Theorems**

| Name | Type / Purpose |
|------|----------------|
| `Algebra.FiniteType` | Class: `R → A` algebra is *finitely generated as an algebra* over `R`, i.e., the unit subalgebra `⊤ : Subalgebra R A` is finitely generated (`FG`). |
| `RingHom.FiniteType` | Predicate on ring homomorphisms `f : A →+* B`: `B` is finitely generated as an `A`-algebra via `f`. |
| `AlgHom.FiniteType` | Predicate on algebra morphisms `f : A →ₐ[R] B`: `f.toRingHom.FiniteType`. |
| `Algebra.FiniteType.self` | `R` is finitely generated as an algebra over itself. |
| `Algebra.FiniteType.polynomial` | `R[X]` is finitely generated as an `R`-algebra (generated by `X`). |
| `Algebra.FiniteType.freeAlgebra` | `FreeAlgebra R ι` is finitely generated if `ι` is finite (generated by `ι '' univ`). |
| `Algebra.FiniteType.mvPolynomial` | `MvPolynomial ι R` is finitely generated if `ι` is finite (generated by `X '' univ`). |
| `Algebra.FiniteType.of_surjective` | If `A` is fg over `R`, and `A →ₐ[R] B` is surjective, then `B` is fg over `R`. |
| `Algebra.FiniteType.trans` | Transitivity: if `S` is fg over `R`, and `A` is fg over `S`, then `A` is fg over `R`. |
| `Algebra.FiniteType.iff_quotient_freeAlgebra` | `A` is fg over `R` ⇔ `A ≅ FreeAlgebra R s ⧸ ker f` for some finite `s : Finset A`. |
| `Algebra.FiniteType.iff_quotient_mvPolynomial` | Same as above, but with `MvPolynomial`. |
| `Algebra.FiniteType.isNoetherianRing` | If `R` is Noetherian and `S` is fg over `R`, then `S` is Noetherian. |
| `AddMonoidAlgebra.finiteType_iff_fg` | For `R` nontrivial commutative ring, `R[M]` is fg as `R`-algebra ⇔ `M` is finitely generated as additive monoid. |
| `MonoidAlgebra.finiteType_iff_fg` | Same for monoid algebras: `R[M]` fg ⇔ `M` fg monoid. |
| `CommRing.orzechProperty` | Any commutative ring `R` satisfies Orzech’s property: surjective endomorphisms of fg modules are iso. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `finiteType`: used for predicates on algebras, ring homs, and algebra homs.
  - `fg`: used in `Subalgebra.FG`, `Module.Finite`, `AddMonoid.FG`, `Monoid.FG`, etc.
  - `of_`: e.g., `of_surjective`, `of_restrictScalars_finiteType`, `of_comp_finiteType`.
  - `iff_`: for biconditional characterizations (e.g., `iff_quotient_freeAlgebra`).
- **Suffixes**:
  - `_type`: e.g., `finiteType`, `fg`.
  - `_iff_`: for equivalence theorems.
- **Pattern**:
  - `Algebra.FiniteType.{type}` for algebra-level properties.
  - `RingHom.FiniteType.{type}` / `AlgHom.FiniteType.{type}` for morphism-level.
  - `fg_of_`, `finiteType_of_`: for constructing finiteness from other data.

#### **4. Proof Logic**

- **Structure of proofs**:
  - **Forward direction** (`→`): Given `FiniteType R A`, extract finite generating set `s`, then construct map from `FreeAlgebra R s` or `MvPolynomial s R` and show surjectivity via `adjoin`/`aeval` properties.
  - **Backward direction** (`←`): Given a surjection from a known fg algebra (e.g., `FreeAlgebra R ι`), apply `of_surjective`.
- **Common lemmas used**:
  - `adjoin_eq_range_freeAlgebra_lift`, `adjoin_eq_range`, `AlgHom.coe_range`, `Set.mem_range`, `Set.mem_univ`.
  - `Subalgebra.fg_top`, `fg_trans'`, `map_top`.
- **Induction patterns**:
  - For algebras: `induction_on` (e.g., on `FreeAlgebra`, `MvPolynomial`, `AddMonoidAlgebra`) with cases for `1`, `+`, `*`, `•`.
- **Reduction to known cases**:
  - Use `trans`, `of_restrictScalars_finiteType`, `of_surjective`, `equiv`.
- **Orzech property proof**:
  - Reduce to Noetherian subring `A` generated by coefficients of relations.
  - Restrict modules to `A`, apply Noetherian case, then descend back.

#### **Domain-Specific AI Agent Notes**

- **Core domain**: Commutative algebra, especially finite type conditions, module/finiteness, and algebra presentations.
- **Key reasoning patterns**:
  - Equating finite generation with existence of surjection from polynomial/free algebra.
  - Transferring finiteness along surjections, compositions, and scalar restriction.
  - Relating algebraic finite generation to monoid/additive monoid finite generation (via monoid/algebra constructions).
- **Critical lemmas for automation**:
  - `iff_quotient_freeAlgebra`, `iff_quotient_mvPolynomial`, `finiteType_iff_fg`, `fg_of_finiteType`.

- **Common pitfalls**:
  - Coercion subtleties (`↑s`, `of R M`, `of' R M`).
