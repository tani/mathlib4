### Technical Metadata Brief: Rees Algebra in Lean 4 (Mathlib)

---

#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `reesAlgebra` | `Ideal R → Subalgebra R R[X]` | Defines the Rees algebra of an ideal `I` as the subalgebra of polynomials whose `i`-th coefficient lies in `I^i`. |
| `mem_reesAlgebra_iff` | `f ∈ reesAlgebra I ↔ ∀ i, f.coeff i ∈ I ^ i` | Characterizes membership in the Rees algebra via coefficients. |
| `mem_reesAlgebra_iff_support` | `f ∈ reesAlgebra I ↔ ∀ i ∈ f.support, f.coeff i ∈ I ^ i` | Refines membership to only support indices (coefficients outside support are zero, which lie in all powers of `I`). |
| `reesAlgebra.monomial_mem` | `monomial i r ∈ reesAlgebra I ↔ r ∈ I ^ i` | Gives a simple criterion for when a monomial lies in the Rees algebra. |
| `monomial_mem_adjoin_monomial` | `r ∈ I ^ n ⇒ monomial n r ∈ Algebra.adjoin R (monomial 1 '' I)` | Shows that higher-degree monomials lie in the algebra generated by degree-1 monomials from `I`. |
| `adjoin_monomial_eq_reesAlgebra` | `Algebra.adjoin R (monomial 1 '' I) = reesAlgebra I` | Proves the Rees algebra is generated by degree-1 elements (`monomial 1 r` for `r ∈ I`). |
| `reesAlgebra.fg` | `I.FG ⇒ (reesAlgebra I).FG` | If `I` is finitely generated, then its Rees algebra is finitely generated as an `R`-algebra. |
| `instance [IsNoetherianRing R] : Algebra.FiniteType R (reesAlgebra I)` | `R` Noetherian ⇒ Rees algebra is of finite type over `R`. | Enables Noetherianity preservation. |
| `instance [IsNoetherianRing R] : IsNoetherianRing (reesAlgebra I)` | Rees algebra over a Noetherian ring is itself Noetherian. | Key consequence for applications like Artin–Rees. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `reesAlgebra.`: For definitions and theorems directly about the Rees algebra.
  - `mem_`: For membership characterizations (`mem_reesAlgebra_iff`, `mem_reesAlgebra_iff_support`).
  - `monomial_`: For lemmas about monomials in relation to the Rees algebra.
- **Suffixes**:
  - `_iff`: Biconditional characterizations.
  - `_mem`: Membership criteria.
  - `_fg`: Finitely generated properties.
- **Function names**:
  - `adjoin_monomial_eq_reesAlgebra`: Equality between two constructions.
  - `reesAlgebra.fg`: Property of finite generation.

- `induction' n with n hn`: Induction on natural numbers.
- `Submodule.smul_induction_on`: For proving properties over modules generated by multiplication.
- `apply le_antisymm`: To prove equality of sets/subalgebras.
- `change`, `rw [Finset.coe_image]`, `rw [Submodule.map_span]`: Advanced rewriting for set-theoretic and module-theoretic expressions.

#### **4. Proof Logic**

- **Structure of proofs**:
  - **Membership characterizations**: Reduce to coefficient-wise conditions using `coeff_*` lemmas.
  - **Equality of subalgebras**: Prove inclusion both ways (`le_antisymm`), often via:
    - Showing generators of one side lie in the other.
    - Expanding arbitrary elements (e.g., via `as_sum_support`) and using closure properties.
  - **Finite generation**:
    - Use `adjoin_monomial_eq_reesAlgebra` to reduce to algebra generated by `monomial 1 '' I`.
    - Lift finite generating set of `I` via `monomial 1` and apply `Algebra.adjoin_span`.
  - **Induction**: Used in `monomial_mem_adjoin_monomial` to lift monomials of degree `n` to algebra generated by degree-1 monomials.

- **Logical flow**:
  - Define object → characterize membership → show generation by simpler elements → prove finite generation → deduce Noetherianity.
