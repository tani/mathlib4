**Technical Brief: `Zero.lean` — Zero-Dimensional Rings in Lean 4**

---

### 1. **Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `Ring.KrullDimLE.mem_minimalPrimes_iff` | `I ∈ J.minimalPrimes ↔ I.IsPrime ∧ J ≤ I` | Characterizes membership in minimal primes over `J` in zero-dimensional rings. |
| `Ring.KrullDimLE.mem_minimalPrimes_iff_le_of_isPrime` | `I ∈ J.minimalPrimes ↔ J ≤ I` (when `I.IsPrime`) | Simplifies the above when the candidate prime is already known. |
| `Ring.KrullDimLE.minimalPrimes_eq_setOf_isPrime` | `minimalPrimes R = { I | I.IsPrime }` | In zero-dimensional rings, *all* prime ideals are minimal. |
| `Ring.KrullDimLE.minimalPrimes_eq_setOf_isMaximal` | `minimalPrimes R = { I | I.IsMaximal }` | In zero-dimensional *local* rings, all primes are maximal (and vice versa). |
| `Ring.KrullDimLE.isField_of_isDomain` | `[IsDomain R] → IsField R` | A zero-dimensional integral domain is a field. |
| `ringKrullDimZero_iff_ringKrullDim_eq_zero` | `Ring.KrullDimLE 0 R ↔ ringKrullDim R = 0` | Equivalence between the `KrullDimLE` predicate and actual Krull dimension being zero (for nontrivial rings). |
| `Ring.krullDimLE_zero_and_isLocalRing_tfae` | `List.TFAE [...]` | 4 equivalent conditions for a *local* zero-dimensional ring: uniqueness of prime ideal, nilpotents = nonunits, maximal nilradical. |
| `Ring.KrullDimLE.existsUnique_isPrime` | `∃! I, I.IsPrime` | In a local zero-dimensional ring, there is a unique prime ideal. |
| `Ring.KrullDimLE.eq_maximalIdeal_of_isPrime` | `J.IsPrime → J = maximalIdeal` | Any prime ideal equals the unique maximal ideal in such a ring. |
| `Ring.KrullDimLE.radical_eq_maximalIdeal` | `I ≠ ⊤ → I.radical = maximalIdeal` | Any proper ideal has radical equal to the maximal ideal. |
| `Ring.KrullDimLE.subsingleton_primeSpectrum` | `Subsingleton (PrimeSpectrum R)` | The prime spectrum has at most one point (i.e., is contractible). |
| `Ring.KrullDimLE.isNilpotent_iff_mem_maximalIdeal` | `IsNilpotent x ↔ x ∈ maximalIdeal` | Nilpotents coincide with the maximal ideal. |
| `Ring.KrullDimLE.nilradical_eq_maximalIdeal` | `nilradical R = maximalIdeal` | Nilradical equals the unique maximal ideal. |
| `PrimeSpectrum.unique_of_ringKrullDimLE_zero` | `Unique (PrimeSpectrum R)` | In a local zero-dimensional ring, the prime spectrum has exactly one point. |
| `Ideal.jacobson_eq_radical` | `I.jacobson = I.radical` | In zero-dimensional rings, Jacobson and radical ideals coincide. |
| `IsJacobsonRing` instance | `[Ring.KrullDimLE 0 R] → IsJacobsonRing R` | Zero-dimensional rings are Jacobson rings. |

### 2. **Naming Conventions**

- **Prefixes**:
  - `Ring.KrullDimLE.` — for lemmas/theorems assuming `KrullDimLE 0 R`.
  - `is_` / `mem_` — for membership or property predicates (`isPrime`, `isMaximal`, `isNilpotent`, `mem_minimalPrimes`).
  - `le_` — for inequalities involving ideals (`le_maximalIdeal`, `le_isUnit_iff_zero_notMem`).
  - `radical_`, `nilradical_`, `jacobson_` — for radical-related operations.

- **Suffixes**:
  - `_iff` — for biconditional characterizations.
  - `_eq_` — for equality lemmas (e.g., `eq_maximalIdeal_of_isPrime`).
  - `_tfae` — “the following are equivalent” (used in `tfae` proofs).
