#### **2. Naming Conventions**

- **Prefixes**:
  - `isNilpotent_`: predicates nilpotency.
  - `isUnit_`: predicates invertibility.
  - `fst_`, `snd_`: refer to component projections in `TrivSqZeroExt`.
  - `ideal_`: ideal-theoretic results.
  - `inst_`: typeclass instance definitions (`instIsLocalRing`, `instIsPrincipalIdealRing`).
- **Suffixes**:
  - `_iff_`: biconditional characterizations.
  - `_eq_zero`: characterizations involving zero.
  - `_dvd_`: divisibility conditions.
  - `_singleton_`: ideal generated by a singleton (e.g., `span {ε}`).
- **Notable abbreviations**:
  - `ε`: the canonical nilpotent generator (`ε = .inr 1`).
  - `inl`, `inr`: canonical injections into `TrivSqZeroExt`.

#### **4. Proof Logic**

- **Structure**: Proofs follow a *component-wise analysis* strategy:
  1. Reduce properties (unit, nilpotent, divisibility) to statements about `fst` and `snd` using lemmas like `isNilpotent_iff_isNilpotent_fst`.
  2. Use structural properties of `TrivSqZeroExt` (e.g., multiplication rules, ε behavior) to simplify.
  3. For ideal classification (`ideal_trichotomy`):
     - Assume ideal is non-zero and proper.
     - Show every element is divisible by ε.
     - Use existence of non-zero elements to construct ε as a multiple, proving ideal = ⟨ε⟩.
  4. For local ring / PID properties:
     - Use ideal trichotomy to enumerate all ideals.
     - Verify local ring condition via `isUnit_or_isUnit_of_add_one`.
     - Verify PID condition by checking principal generation for the three ideal cases.

- **Induction**: Not used — proofs rely on algebraic structure and case analysis.

- **Classical reasoning**: Used via `em` (excluded middle) in `isUnit_or_isNilpotent_of_isMaximal_isNilpotent`.
