### Technical Brief: `Inverse.lean` — Inverse Operator for Fractional Ideals

---

#### **1. Key Definitions & Theorems**

| Name | Type / Statement | Purpose |
|------|------------------|---------|
| `FractionalIdeal.instInv` | `Inv (FractionalIdeal R⁰ K)` | Defines the notation `I⁻¹` as `1 / I` for fractional ideals. |
| `inv_eq` | `I⁻¹ = 1 / I` | Justifies the notation: inverse is defined via division. |
| `inv_zero'` | `(0 : FractionalIdeal)⁻¹ = 0` | Handles zero ideal: its inverse is zero (non-invertible). |
| `inv_of_ne_zero` | `J ≠ 0 → J⁻¹ = ⟨1 / J, ...⟩` | Explicit description of inverse when `J ≠ 0`. |
| `coe_inv_of_ne_zero` | `(↑J⁻¹ : Submodule R K) = K ⊤ / J` | Describes the underlying submodule of `J⁻¹`. |
| `mem_inv_iff` | `x ∈ I⁻¹ ↔ ∀ y ∈ I, x*y ∈ 1` | Membership characterization: elements of `I⁻¹` multiply `I` into `R`. |
| `inv_anti_mono` | `I ≤ J → J⁻¹ ≤ I⁻¹` | Inversion reverses inclusion (contravariance). |
| `le_self_mul_inv` | `I ≤ 1 → I ≤ I * I⁻¹` | General inequality used in invertibility criteria. |
| `right_inverse_eq` | `I * J = 1 → J = I⁻¹` | Uniqueness of inverse when it exists. |
| `mul_inv_cancel_iff` | `I * I⁻¹ = 1 ↔ ∃ J, I * J = 1` | Connects invertibility with existence of a two-sided inverse. |
| `mul_inv_cancel_iff_isUnit` | `I * I⁻¹ = 1 ↔ IsUnit I` | Links invertibility in `FractionalIdeal` to being a unit. |
| `map_inv` | `I⁻¹.map h = (I.map h)⁻¹` | Compatibility of inversion with `R`-algebra isomorphisms. |
| `spanSingleton_inv` | `(⟨x⟩)⁻¹ = ⟨x⁻¹⟩` | Inverse of a principal fractional ideal is principal generated by inverse. |
| `spanSingleton_mul_inv`, `spanSingleton_inv_mul` | `⟨x⟩ * ⟨x⟩⁻¹ = 1`, etc. | Principal fractional ideals generated by nonzero `x` are invertible. |
| `invertible_of_principal` | `I` principal & nonzero ⇒ `I * I⁻¹ = 1` | Principal nonzero fractional ideals are invertible. |
| `invertible_iff_generator_nonzero` | `I * I⁻¹ = 1 ↔ generator(I) ≠ 0` | For principal `I`, invertibility ⇔ generator ≠ 0. |
| `isPrincipal_inv` | `I` principal & nonzero ⇒ `I⁻¹` principal | Inverse of a principal nonzero fractional ideal is principal. |
| `den_mem_inv` | `den(I) ∈ I⁻¹` when `I ≠ ⊥` | Denominator of `I` lies in its inverse. |
| `num_le_mul_inv` | `I.num ≤ I * I⁻¹` | Numerator ideal is contained in `I * I⁻¹`. |
| `bot_lt_mul_inv` | `I ≠ ⊥ → ⊥ < I * I⁻¹` | Strict inequality: `I * I⁻¹` is nonzero. |
| `InvOneClass (FractionalIdeal R⁰ K)` | `inv_one = div_one` | Ensures `1⁻¹ = 1`. |

#### **2. Naming Conventions**

- **Prefixes**:
  - `inv_`: properties of inversion (`inv_eq`, `inv_zero'`, `inv_of_ne_zero`, etc.)
  - `coe_inv_`: coercion to `Submodule` (`coe_inv_of_ne_zero`)
  - `spanSingleton_`: for principal fractional ideals (`spanSingleton_inv`, `spanSingleton_mul_inv`)
  - `coe_ideal_`: for ideals coerced to fractional ideals (`coe_ideal_span_singleton_mul_inv`)
  - `den_`, `num_`: denominator/numerator-related (`den_mem_inv`, `num_le_mul_inv`)
- **Suffixes**:
  - `_iff`: characterizations (`mem_inv_iff`, `invertible_iff_generator_nonzero`)
  - `_le_`, `_lt_`: order-theoretic statements (`inv_anti_mono`, `bot_lt_mul_inv`)
  - `_self`: self-interaction (`mul_inv_cancel_iff`, `spanSingleton_div_self`)
- **`⁻¹` notation**: used uniformly for inversion; defined via `Inv` typeclass.

Frequent tactics used in proofs:
- `rw` / `simp_rw`: rewriting definitions (`inv_eq`, `mem_inv_iff`, `spanSingleton_inv`)
- `simp`: simplification with `isPrincipal_iff`, `mem_div_iff_of_ne_zero`, etc.
- `intro` / `exact`: standard intro/elimination in implications
- `conv`: for localized rewriting (`conv_lhs => congr; rw [...]`)
- `gcongr`: for monotonicity arguments (`num_le_mul_inv`)
- `apply`, `have`, `suffices`: intermediate lemma construction
- `rwa`, `apply`, `contradiction`: in equivalence/contradiction proofs
- `lt_of_lt_of_le`, `le_trans`: order reasoning
- `div_one`, `div_zero`, `mul_inv_cancel₀`: arithmetic lemmas from `Field`/`DivisionRing`

#### **4. Proof Logic**

- **Structure**:
  - Most proofs follow a pattern:
    1. Unfold definitions (`inv_eq`, `mem_inv_iff`, `coe_inv_of_ne_zero`)
    2. Use `mem_div_iff_of_ne_zero` to reduce membership in `1/I` to `x·I ⊆ R`
    3. Apply monotonicity or containment lemmas (`inv_anti_mono`, `num_le_mul_inv`)
    4. For principal ideals: reduce to `spanSingleton`, then use field arithmetic (`mul_inv_cancel₀`)
  - **Induction**: Not used directly; instead, structural reduction via `isPrincipal_iff` and generator properties.
  - **Case analysis**: on `I = 0` or `I ≠ 0`, or `I = ⊥` (zero submodule).
  - **Equivalence proofs**: split into `→` and `←`, often using `right_inverse_eq` or `invertible_iff_exists_inv`.

#### **7. Summary**

This file formalizes the *formal inverse* `I⁻¹ := 1 / I` for fractional ideals, distinguishing between:
- **General case**: `I⁻¹` always exists (as `1/I`), but may not satisfy `I·I⁻¹ = 1`.
- **Invertible case**: `I·I⁻¹ = 1` iff `I` is a unit, and this holds for all nonzero principal fractional ideals.

The theory bridges abstract localization (via `FractionalIdeal`) and concrete ideal arithmetic, laying groundwork for Dedekind domain theory (where *all* nonzero fractional ideals are invertible). The notation `I⁻¹` is justified only when invertibility holds — a subtlety acknowledged in the docstring.
