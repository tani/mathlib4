#### **1. Key Definitions & Theorems**

| Name | Type / Signature | Purpose |
|------|------------------|---------|
| `IsBezout R` | `Class` (implicit via `CommRing R`) | A ring `R` is a *Bézout ring* if every finitely generated ideal is principal. |

#### **4. Proof Logic / Strategy**

- **`iff_span_pair_isPrincipal`**:
  - Uses *submodule induction* (`Submodule.fg_induction`) to reduce from arbitrary finitely generated ideals to those generated by two elements.
  - Base case: `⊥` (zero ideal) is principal.
  - Inductive step: uses `span_insert` to build up ideals and applies hypothesis on `{x, y}`.

- **`Function.Surjective.isBezout`**:
  - Lifts elements `x, y ∈ S` via surjectivity to `x̃, ỹ ∈ R`.
  - Uses `gcd` in `R`, maps it forward, and shows `span {x, y} = span {f(gcd x̃ ỹ)}` via ideal map properties.

- **`TFAE`**:
  - Uses `List.TFAE` infrastructure to prove a cycle of implications.
  - Key nontrivial direction: `4 → 1` (WfDvdMonoid ⇒ Noetherian):
    - Constructs a well-founded embedding from `({ J // J.FG }, ≤)` (divisibility of generators) to `ℕ`-like well-founded relation via `choose f hf`.
    - Relies on Bézout + domain to identify ideals with principal generators and relate inclusion to divisibility:  
      `I ≤ J ↔ generator J ∣ generator I`.
    - Applies `wf_dvd_monoid_iff_well_founded` (via `isNoetherian_iff_fg_wellFounded`).
